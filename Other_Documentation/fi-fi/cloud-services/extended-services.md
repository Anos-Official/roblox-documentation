# Laajennetut palvelut

English

* This content is translated using AI (Beta) and may contain errors. To view this page in English, click [here] .

Laajennetut palvelut ovat ratkaisu, joka antaa sinun hallita palvelinkäyttöä ja maksamista yli Robloxin oletusrajojen. Se sisältää tietovarastot, muistivarastot, tekstistä puheeksi, puheesta tekstiksi ja laskentatehon.

## [Kelpoisuusvaatimukset](#kelpoisuusvaatimukset)[](#kelpoisuusvaatimukset)

Käyttääksesi laajennettuja palveluja, Roblox-tilisi on:

-

Oltava [ID-vahvistettu](/docs/en-us/production/publishing/account-verification#verify-through-government-id)  ja 18 vuotta tai vanhempi.

-

Oltava sijainti [tuetussa maassa](#tuetut-maat) .

-

Oltava voimassa oleva sähköpostiosoite liitettynä siihen.

-

Ei saa olla tällä hetkellä estetty tai valvottu.

-

Hyväksyttävä ja noudatettava [palveluehtoja](https://en.help.roblox.com/hc/articles/37967848292500) .

Ryhmätilien osalta vain ryhmän omistajan on täytettävä kelpoisuusvaatimukset.

## [Laajennettujen palvelujen avaaminen](#laajennettujen-palvelujen-avaaminen)[](#laajennettujen-palvelujen-avaaminen)

Jos täytät kaikki [kelpoisuusvaatimukset](#kelpoisuusvaatimukset) , voit viimeistellä laajennettujen palvelujen asetukset syöttämällä tilitietosi ja maksutietosi. Ryhmän omistamissa peleissä vain ryhmän omistaja voi avata laajennetut palvelut ja ottaa pelin käyttöön.

Avaaksesi ja käyttääksesi laajennettuja palveluja:

1.

Siirry [Luojapaneeliin](https://create.roblox.com/dashboard/creations) , mene kohtaan Luomukset  ja valitse peli.

2.

Siirry kohtaan Laajennetut palvelut .

3.

Jos et ole vielä syöttänyt tilitietojasi ja maksutietojasi, napsauta yläpalkissa Lisää puuttuvat tiedot .

1.

Syötä tilitietosi. Tilityyppi , Verotunnustyyppi  ja Verotunnus  -kentät ovat valinnaisia.

-

Voit myös siirtyä kohtaan Rahoitus  ⟩ Tilitiedot  laajennettujen palvelujen osiossa hallitaksesi tilitietojasi. Sinun ei tarvitse päivittää mitään muuta tällä sivulla.

2.

Napsauta Seuraava .

3.

Syötä maksutapa. Voit syöttää uuden maksutavan tai valita jo käytössä olevista maksuvaihtoehdoista, jotka on liitetty Roblox-tiliisi.

-

Voit myös siirtyä kohtaan Rahoitus  ⟩ Maksut  lisätäksesi uusia maksutapoja tai siirtyä kohtaan Rahoitus  ⟩ Laskutus  asettaaksesi uuden oletusmaksutavan.

4.

Napsauta Tallenna .

## [Palvelun aktivointi](#palvelun-aktivointi)[](#palvelun-aktivointi)

Aktivoidaksesi palvelun:

1.

Siirry kohtaan Laajennetut palvelut .

2.

Kytke päälle palvelu, jonka haluat aktivoida.

3.

Syötä kuukausibudjetti jokaiselle soveltuvalle resurssille palvelun alla. Minimikuukausibudjetti, jonka voit asettaa, on 0,50 USD.

Maksutapaasi veloitetaan joko kuukauden lopussa, kun lasku luodaan, tai kun käyttösi saavuttaa 10 USD, kumpi tahansa tapahtuu ensin.

Voit nostaa tai laskea palvelun kuukausibudjettia milloin tahansa. Palvelusi rajoitetaan automaattisesti, jos lasket budjettisi alle nykyisen kuukauden käyttösi, tai jos ylität asettamasi budjetin.

Roblox ilmoittaa sinulle sähköpostitse, kun käyttösi saavuttaa 80% budjetistasi, ja sitten uudelleen, kun se saavuttaa 100%.

### [Laajennetut palvelut laskentateholle](#laajennetut-palvelut-laskentateholle)[](#laajennetut-palvelut-laskentateholle)

Jokaisella pelipalvelimella on oletusmäärä CPU:ta, joka kasvaa jokaisen pelaajan myötä, joka liittyy peliin. Laajennetut palvelut laskentateholle  kaksinkertaistaa per-pelaaja CPU:n, jonka pelisi palvelimet saavat.

Suurin osa peleistä Robloxissa ei hyödy tästä palvelusta, mutta pelit, joissa on raskasta palvelinpuolen fysiikkaa tai jotka käyttävät laajasti [palvelinvaltaa](/docs/en-us/projects/server-authority) , saavuttavat olemassa olevat rajat. Tarkistaaksesi, voiko pelisi hyötyä laajennetuista palveluista laskentateholle :

-

Tarkista [palvelimen sydänlyönti](/docs/en-us/performance-optimization/identify#server-compute)  jatkuvista pudotuksista alle 60 FPS.

-

Tarkista CPU-ytimen käyttö [Suorituskykypaneelissa](/docs/en-us/production/analytics/performance#server-charts) .

Ennen kuin maksat lisää CPU:ta, yritä [vähentää palvelimiesi työkuormaa](/docs/en-us/performance-optimization/improve) .

## [Hallitse laskutusta](#hallitse-laskutusta)[](#hallitse-laskutusta)

Päästäksesi laajennettujen palvelujen laskutuspaneeliin:

1.

Siirry kohtaan Rahoitus  ⟩ Laskutus .

2.

Valitse Pilvipalvelut -välilehti, jotta voit näyttää seuraavat tiedot:

-

Odottava saldo, mukaan lukien kuukauden kustannukset

-

Laskutushistoria, mukaan lukien kaikki laajennettujen palvelujen laskutustoiminta peleissäsi

Saadaksesi yksityiskohtaisen erittelyn nykyisistä odottavista saldoista, napsauta Näytä tiedot  maksutapasi vieressä. Saadaksesi yksityiskohtaisen laskun aikaisemmasta laskusta, napsauta Näytä lasku  kohdassa Laskutushistoria .

## [Palveluhinnat](#palveluhinnat)[](#palveluhinnat)

Katso seuraava taulukko laajennettujen palvelujen hinnoista:

| Palvelu | |  | | Oletus | | Laajennettu |
| [Muistivarastot](https://create.roblox.com/docs/cloud-services/memory-stores) | | Pyynnöt | | 1000 + (CCU × 120) pyyntöä minuutissa | | 0,003 USD / 1M pyyntöä |
|  | | Varasto | | 64 KB + (CCU × 1,2 KB) | | 0,10 USD / GB per tunti¹ |
| [Tekstistä puheeksi](https://create.roblox.com/docs/audio/objects#text-to-speech) | | Pyynnöt | | 1 + (CCU × 6) pyyntöä minuutissa | | 5,00 USD / 1M pyyntöä |
| [Puheesta tekstiksi](https://create.roblox.com/docs/audio/objects#speech-to-text) | | Pyynnöt | | 1 + (CCU × 5) pyyntöä minuutissa | | 1 USD / 1M pyyntöä |
| [Standarditietovarastot](https://create.roblox.com/docs/cloud-services/data-stores) | | Hae | | 250 + (CCU * 40) pyyntöä minuutissa | | 0,08 USD / 1M pyyntöä |
|  | | Aseta | | 250 + (CCU * 20) pyyntöä minuutissa | | 0,80 USD / 1M pyyntöä |
|  | | Luettelo | | 10 + (CCU * 2) pyyntöä minuutissa | | 0,60 USD / 1M pyyntöä |
|  | | Poista | | 100 + (CCU * 40) pyyntöä minuutissa | | 0,80 USD / 1M pyyntöä |
| [Järjestetyt tietovarastot](https://create.roblox.com/docs/cloud-services/data-stores) | | Hae | | 250 + (CCU * 40) pyyntöä minuutissa | | 0,08 USD / 1M pyyntöä |
|  | | Aseta | | 250 + (CCU * 20) pyyntöä minuutissa | | 0,25 USD / 1M pyyntöä |
|  | | GetSorted | | 100 + (CCU * 2) pyyntöä minuutissa | | 0,32 USD / 1M pyyntöä |
|  | | Poista | | 100 + (CCU * 40) pyyntöä minuutissa | | 0,25 USD / 1M pyyntöä |
| [Tietovaraston varasto](https://create.roblox.com/docs/cloud-services/data-stores) | | Varasto | | 100 MB + (1 MB * Elinikäpelaajat) GB kuukaudessa | | 0,12 USD / GB kuukaudessa |
| [Laskenta](https://create.roblox.com/docs/production/analytics/performance) | | CPU-ytimiä | | Ensimmäiset 100K pelituntia kuukaudessa ilman maksua (kun on rekisteröitynyt laajennettuihin palveluihin laskentateholle) | | 0,001 USD / pelitunti² |

 ¹ GB per tunti = varastokulutus kerrottuna ajalla. Esimerkiksi 100 GB tuntia voi vastata "100 GB × 1 tunti" tai "200 GB × 0,5 tuntia".  ² Laajennetut palvelut laskentateholle veloitetaan sen mukaan, kuinka kauan ominaisuus on ollut käytössä, mitattuna pelituntien minuuteissa. Koska ominaisuuden aktivointi varaa lisälaskentatehoa pelillesi, maksut tulevat voimaan aina, kun ominaisuus on aktiivinen, vaikka lisälaskentatehoa ei käytettäisikään täysin. Pelitunnit lasketaan kaikkien pelaajasessioiden kestojen summana. Esimerkiksi, jos 10 000 käyttäjää pelaa kukin 1 tunnin, se tarkoittaa 10 000 pelituntia, mikä johtaa 10 USD:n maksuihin yli 100 000 pelitunnin kuukausittaisen sisältyvän rajan. Nämä rajat ja hinnat koskevat vain pelejä, jotka on rekisteröity laajennettuihin palveluihin laskentateholle. Pelit, jotka eivät rekisteröidy, saavat edelleen rajattomat pelitunnit nykyisten oletusrajojen mukaan ilman lisämaksua.
