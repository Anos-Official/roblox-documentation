# Get started for experienced creators

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/onboarding/index.md)

If your team already ships games on other engines or platforms, most of what you know carries over to Roblox. A few fundamentals work differently, and learning them first saves rework later. This section collects what you need in your first weeks on Roblox.

A few terms come up everywhere:

-

Game:  The overall project that players join. A game is a collection of places, and services like data stores, analytics, and in-game purchases are scoped to it.

-

Place:  A discrete scene or zone within a game, such as a lobby or a level. Each server runs one place.

-

Studio:  The editor you use to build places, write scripts, and upload assets. You edit one place at a time.

-

Cloud-first:  Places, assets, and scripts are saved to Roblox by default, rather than to files on your disk.

 ![The Roblox Studio user interface with markup to show the various windows and panels.](https://prod.docsiteassets.roblox.com/assets/studio/general/Studio-Layout.png)

## [Key differences from other engines](#key-differences-from-other-engines)[](#key-differences-from-other-engines)

-

Cloud storage:  Studio saves your places, assets, and scripts to Roblox rather than to files on your disk, and your team edits them together in real time with [Team Create](/docs/projects/collaboration) . If you want Git and other file-based tools, see [Compare file-based workflows](/docs/projects/file-based-workflows) .

-

Multiplayer by default:  Every game runs on Roblox servers with a [client-server model](/docs/projects/client-server) , so where you place an object or script determines whether the server, the client, or both can see and run it.

-

Built-in physics:  Parts simulate physics automatically without extra components, and you connect them to each other with [constraints](/docs/physics/mechanical-constraints) .

-

Luau:  Scripts use [Luau](/docs/luau) , a fast, gradually typed language derived from Lua.

-

Materials instead of shaders:  Roblox doesn't support custom shaders, so you build materials with [SurfaceAppearance](/docs/reference/engine/classes/SurfaceAppearance)  and [MaterialVariant](/docs/reference/engine/classes/MaterialVariant)  and create effects with built-in materials and instances.

-

Automatic quality scaling:  Roblox adjusts rendering, lighting, and streaming to each device, which lets the same game run on phones, consoles, and PCs.
