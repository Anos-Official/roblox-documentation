# Maak een project

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Dit curriculum maakt gebruik van de ingebouwde Assistent van Studio voor routinetaken zoals het maken van instanties, het configureren van eigenschappen en het genereren van scripts. Dit stelt je in staat om meer tijd te besteden aan de creatieve aspecten van het bouwen van je game.

Stappen die een Assistent-werkstroom bevatten, bieden een Bouwen met Assistent  tabblad naast een Bouw het Zelf  tabblad. Je kunt beide benaderingen volgen, afhankelijk van hoe je wilt werken.

Om te beginnen met het recreëren van de Island Jump  [3D platformgame](https://www.roblox.com/games/14238807008) , heb je een project nodig om in te bouwen. Een project is een verzameling plaatsen, assets en instellingen die samen een Roblox-game vormen.

De snelste manier om te beginnen is door een Studio-sjabloon te gebruiken. Voor dit project gebruik je de standaard Basisplaat  sjabloon, die een vlakke grond en een [SpawnLocation](/docs/nl-nl/reference/engine/classes/SpawnLocation)  object heeft.

1.

Klik in Roblox Studio op Nieuwe Ervaring  in de linkerbovenhoek.

2.

Breid in het Explorer  venster Workspace  uit en verwijder het Basisplaat  object, zodat het viewport een lege wereld toont met alleen de spawnlocatie in het midden.

Als je het Explorer  venster niet ziet, schakel het dan in via het Venster  menu van Studio.

 ![Een viewportweergave van de basisplaat-sjabloon zonder de basisplaat. De spawnlocatie is gemarkeerd in het midden van het beeld.](https://prod.docsiteassets.roblox.com/assets/tutorials/core-building-and-scripting/Baseplate-Deleted.jpg)

In de volgende sectie leer je hoe je de Terrein Editor  kunt gebruiken om een eilandomgeving rond de spawnlocatie te creëren.
