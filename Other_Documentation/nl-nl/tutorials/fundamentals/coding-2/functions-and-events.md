# Functies en evenementen

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

### [Serie beschrijving](#serie-beschrijving)[](#serie-beschrijving)

Gebruik functies en evenementen om code uit te voeren wanneer je wilt, zo vaak als je wilt. Met functies en evenementen kun je vallen, knoppen, gezondheidsophalingen en meer instellen.

In deze cursus worden functies, parameters, argumenten en het retourneren van waarden behandeld.

### [Doelstellingen en vereisten](#doelstellingen-en-vereisten)[](#doelstellingen-en-vereisten)

| ** Leerdoelen** | |

Leer om code in herbruikbare stukken te plaatsen die functies worden genoemd.

Begrijp wat het betekent dat code "in scope" is.

Stel evenementen in binnen een spel en gebruik ze om de functies te vertellen wanneer ze moeten draaien.

Oefen met het gebruik van functies en evenementen om vallen en knoppen te creëren.

 |
| --- | --- |
| ** Vereisten** | |

Basiskennis van Roblox Studio, zoals het verplaatsen en roteren van onderdelen. Eerdere ervaring met het maken van Script-objecten en het gebruik van variabelen, eigenschappen en strings.
