# Lussen

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

### [Serieomschrijving](#serieomschrijving)[](#serieomschrijving)

In de computerwetenschappen zijn lussen een veelvoorkomend kenmerk in veel scripts, vaak gebruikt om sets van code te herhalen. Deze serie behandelt twee van de meest voorkomende lussen: for- en while-lussen.

### [Doelstellingen en vereisten](#doelstellingen-en-vereisten)[](#doelstellingen-en-vereisten)

| ** Leerdoelen** | |

Begrijp situaties waarin lussen nuttig zijn in tegenstelling tot alternatieve vormen van het schrijven van een script.

Weet hoe je for- en while-lussen schrijft, terwijl je de syntaxis voor beide identificeert.

 |
| --- | --- |
| ** Vereisten** | |

Heb een algemeen begrip van variabelen in Luau.
