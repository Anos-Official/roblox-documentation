# Voorwaardelijke uitspraken

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

### [Serie beschrijving](#serie-beschrijving)[](#serie-beschrijving)

Veel games hebben acties die alleen plaatsvinden als aan een lijst van vereisten is voldaan. Je hebt misschien kamers gezien waar alleen specifieke teams toegang toe hadden of inventarisitems die alleen door sommige spelers konden worden gekocht. Deze serie behandelt hoe je code kunt opzetten die zegt: "Als dit gebeurt, doe dan dat."

### [Doelstellingen en vereisten](#doelstellingen-en-vereisten)[](#doelstellingen-en-vereisten)

| ** Leerdoelen** | |

Begrijp de logica achter if  then -uitspraken en hoe je meerdere scenario's kunt opzetten met de sleutelwoorden elseif  en else .

 |

| ** Vereisten** | |
