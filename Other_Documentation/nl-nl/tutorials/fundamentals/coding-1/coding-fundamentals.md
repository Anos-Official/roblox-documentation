# Basisprincipes van coderen

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

### [Serieomschrijving](#serieomschrijving)[](#serieomschrijving)

Begin met coderen op Roblox met deze gemakkelijk te volgen serie die de basisprincipes van het gebruik van de programmeertaal Luau behandelt. Deze cursussen zijn perfect voor degenen die nieuw zijn in coderen of net beginnen met Luau. Elke cursus richt zich op een fundamenteel principe van computerwetenschappen en bevat individuele lessen met stapsgewijze tutorials die je kunt gebruiken om je eigen games op Roblox te maken.

Voordat je met deze cursus begint, moet de lezer basiskennis van Roblox Studio hebben, zoals aangetoond in de [Studio](/docs/nl-nl/tutorials/curriculums/studio)  en [Bouwen](/docs/nl-nl/tutorials/curriculums/building)  les.

### [Inhoud van de serie](#inhoud-van-de-serie)[](#inhoud-van-de-serie)

| Serie | | Beschrijving |
| --- | --- |
| [Variabelen en objecten](/docs/nl-nl/tutorials/fundamentals/coding-1/landing) | |  Maak je eerste script en begin dingen te laten gebeuren met code. Deze tutorials behandelen variabelen, datatypes en eigenschappen. |
| [Functies en evenementen](/docs/nl-nl/tutorials/fundamentals/coding-2/functions-and-events) | | Gebruik functies om stukken code te maken die alleen draaien wanneer je dat zegt. Verbind je code met gebeurtenissen in de wereld om interactieve objecten zoals vallen of bruggen te creëren. |
| [Voorwaardelijke uitspraken](/docs/nl-nl/tutorials/fundamentals/coding-3/landing) | | Voorwaardelijke uitspraken gebruiken het coderingspatroon van "als dit gebeurt, doe dan dat." Pas dit patroon toe om te controleren of het tijd is om power-ups voor je spelers te ontgrendelen. |
| [Lussen](/docs/nl-nl/tutorials/fundamentals/coding-4/landing) | | Leer hoe je code een bepaald aantal keren kunt herhalen of het voor altijd kunt laten draaien met for- en while-lussen. Oefen met het gebruik van deze lusstypes om getimede bruggen en knipperende lichten te coderen. |
| [Woordenboeken en arrays](/docs/nl-nl/tutorials/fundamentals/coding-5/landing) | | Leer hoe je veel gegevens in een enkele variabele kunt opslaan met behulp van tabellen en arrays. Gegevensstructuren zoals deze kunnen grote datasets opslaan, zoals de inventaris van een speler. |
| [Code organiseren](/docs/nl-nl/tutorials/fundamentals/coding-6/landing) | | Neem je codeorganisatie een stap verder en leer over modulescripts, een uniek type script dat kan interageren met andere scripts in Luau. |
