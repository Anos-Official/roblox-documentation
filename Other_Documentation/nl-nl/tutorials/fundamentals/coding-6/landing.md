# Code organiseren

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

### [Serie beschrijving](#serie-beschrijving)[](#serie-beschrijving)

Naarmate je verder werkt met code, zullen scripts complexer worden. Om dit aan te pakken, hebben programmeurs een verscheidenheid aan technieken om coderen efficiënt, gemakkelijk te begrijpen en de kans op fouten te verminderen. Deze serie behandelt methoden voor het organiseren van scripts, zoals module scripts, een speciaal type script dat functies en variabelen kan opslaan die door andere scripts worden gebruikt.

### [Doelstellingen en vereisten](#doelstellingen-en-vereisten)[](#doelstellingen-en-vereisten)

| ** Leerdoelen** | |

Begrijp de logica achter module scripts, evenals hoe je een module script codeert en deze in andere scripts kunt benaderen.

In staat zijn om patronen van abstractie en algoritmen in de informatica te identificeren.

 |
| --- | --- |
| ** Vereisten** | |

Een begrip hebben van functies, evenementen en if/then-verklaringen.

 |
