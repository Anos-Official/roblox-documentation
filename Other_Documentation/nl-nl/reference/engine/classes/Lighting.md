SetMinutesAfterMidnight

Mogelijkheden: Environment

Lighting:SetMinutesAfterMidnight (minutes :[number](/docs/nl-nl/luau/numbers) ) : ()

Parameters

|

minutes :[number](/docs/nl-nl/luau/numbers)

 |

Teruggaves

()

Codevoorbeelden

Stel Minuten Na Middernacht In

```

local Lighting = game:GetService("Lighting")

local TIME_SPEED = 60  -- 1 min = 1 uur

local START_TIME = 9  -- 9 AM

local minutesAfterMidnight = START_TIME * 60

local waitTime = 60 / TIME_SPEED

while true do

	minutesAfterMidnight = minutesAfterMidnight + 1

	Lighting:SetMinutesAfterMidnight(minutesAfterMidnight)

	task.wait(waitTime)

end

```
