# Verdien geld met je games

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Het bouwen van succesvolle content kost tijd en moeite, maar er is weinig risico en lage initiële kosten verbonden aan het bouwen van een game op Roblox. Je betaalt nadat  je verdient op Roblox en wij bieden de tools, diensten en ondersteuning om je te helpen de meest meeslepende games te bouwen. Roblox heeft een robuuste community en een [ontwikkelaarsforum](https://devforum.roblox.com/)  om je onderweg te begeleiden en te ondersteunen.

Voor een complete lijst van voordelen van monetisatie op Roblox en alle monetisatiepaden op het platform, zie [Zet je creativiteit om in inkomen op Roblox](/docs/nl-nl/monetize) .

## [Monetisatie in de game](#monetisatie-in-de-game)[](#monetisatie-in-de-game)

Monetisatie functies  integreren met je games om inkomsten te genereren. In tegenstelling tot promotionele of advertentiefuncties, richten monetisatiefuncties zich op het creëren van inkomstenstromen in plaats van alleen zichtbaarheid en betrokkenheid.

| Functie | | Beschrijving |
| --- | --- |
| [Creator rewards](/docs/nl-nl/creator-rewards) | | Verdien automatisch Robux wanneer actieve uitgaven betrokken zijn bij je game. Deze uitbetalingen gebeuren automatisch als een manier om boeiende games te belonen. |
| [Private servers](/docs/nl-nl/production/monetization/private-servers) | | Laat gebruikers kiezen wie er kan betalen om een game met hen te spelen. |
| [Subscriptions](/docs/nl-nl/production/monetization/subscriptions) | | Bied gebruikers terugkerende voordelen voor een maandelijkse vergoeding. |
| [Passes](/docs/nl-nl/production/monetization/passes) | | Speciale privileges binnen een game die gebruikers één keer kunnen kopen, zoals toegang tot een beperkt gebied, een in-game avatar item, of een permanente power-up. Wanneer je je eigen passes in je game verkoopt, verdien je 70% van de Robux die wordt uitgegeven. Je kunt ook passes verkopen binnen je game die zijn gemaakt door andere makers; in dit geval verdien je een affiliate vergoeding van 10% op de Robux die binnen je game wordt uitgegeven, en de oorspronkelijke maker van de pass verdient 60%. |
| [Developer products](/docs/nl-nl/production/monetization/developer-products) | | Items of vaardigheden die gebruikers meer dan eens kunnen kopen, zoals in-game valuta, munitie of toverdranken. |
| [Paid access in Robux](/docs/nl-nl/production/monetization/paid-access-robux) | | Vraag gebruikers een eenmalige vergoeding in Robux om toegang te krijgen tot je game. |
| [Paid access in local currency](/docs/nl-nl/production/monetization/paid-access-local-currency) | | Vraag gebruikers een eenmalige vergoeding in hun lokale valuta om toegang te krijgen tot je game. |
| [Managed pricing](/docs/nl-nl/production/monetization/managed-pricing) | | Vind de beste prijsniveaus voor je passes en ontwikkelaarsproducten. |
| [Avatar items](/docs/nl-nl/production/monetization/avatar-items) | | Verkoop avatar items direct binnen je games. |
| [Avatar creation tokens](/docs/nl-nl/production/monetization/avatar-creation-token) | | Laat gebruikers tokens uitgeven om avatar items direct vanuit een game te creëren, kopen en opslaan. |

## [Adverteren](#adverteren)[](#adverteren)

Advertentiefuncties  zijn expliciete advertentietools die gericht zijn op het bereiken van een specifiek publiek. Ze functioneren als traditionele advertenties en hun doel is om betrokkenheid en inkomsten te genereren.

| Functie | | Beschrijving |
| [Ads Manager](/docs/nl-nl/production/promotion/ads-manager) | | Een gecentraliseerd platform waar je advertentiecampagnes kunt maken en meten en je promotionele inspanningen kunt stroomlijnen. |
| [Roblox-served ads vs. independent ads](/docs/nl-nl/production/promotion/advertise-on-roblox) | | Maak onderscheid tussen de door Roblox geserveerde advertenties en de onafhankelijke advertenties die je in je game kunt implementeren. |
| [Immersive ads](/docs/nl-nl/production/monetization/immersive-ads) | | Integreer video-advertenties, afbeeldingsadvertenties en portaaladvertenties om gebruikers advertenties te tonen zonder de gameplay te verstoren. |
| [Search ads](/docs/nl-nl/production/promotion/ads-manager) | | Richt je op specifieke zoekwoorden die relevant zijn voor je game en vergroot de kans op ontdekking via zoekresultaten. |
| [Rewarded video](/docs/nl-nl/production/promotion/rewarded-video-ads) | | Beloningen video-plaatsingen zijn full-screen, horizontale, 6-30 seconden video-advertenties die gebruikers bekijken in ruil voor een beloning. |
