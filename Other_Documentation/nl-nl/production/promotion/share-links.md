# Delen van links

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Deelbare links zijn unieke en traceerbare links die metrics genereren waarmee je je gebruikersacquisitie buiten het platform kunt volgen en laten groeien. Je kunt deelbare links maken voor je games (ervaring links) en voor je avatar-items en bundels (Marketplace links). Voor ervaring links kun je ook aangepaste [LaunchData](/docs/nl-nl/reference/engine/classes/Player#GetJoinData)  gebruiken om in-game voordelen te bieden aan gebruikers die via je deelbare link deelnemen.

De analytics die beschikbaar zijn voor ervaring links omvatten metrics zoals het aantal nieuwe gebruikers dat via een deelbare link op de pagina met game-details is aangekomen, en welk extern kanaal de meest betrokken gebruikers heeft binnengebracht. Er is geen limiet aan het aantal ervaring links dat je per game kunt maken.

De analytics die beschikbaar zijn voor Marketplace links omvatten metrics zoals het aantal gebruikers dat op je link heeft geklikt en hoeveel aankopen er via deze link zijn gedaan. Je kunt tot 20 actieve Marketplace links per item hebben.

Voor beide linktypes kan het maken van verschillende links voor verschillende kanalen je helpen om acquisitiemetrics beter bij te houden.

Voor meer informatie over de analytics voor ervaring links, zie de [Acquisitie](/docs/nl-nl/production/analytics/acquisition)  pagina.

## [Maak een ervaring link](#maak-een-ervaring-link)[](#maak-een-ervaring-link)

Je kunt alleen deelbare links maken voor games die je bezit. Voor groepsgames moet je lid zijn van de groep met de Beheer deelbare links  toestemming, en de deelbare link moet worden gemaakt vanuit het groepsaccount.

Om een ervaring link te maken:

1.

Ga in het [Creator Dashboard](https://create.roblox.com/dashboard/creations)  naar Creations , selecteer het tabblad Share Links  en selecteer vervolgens Experience Links .

2.

Klik op Create link .

3.

Voer een unieke campagnenaam in en selecteer de game waarvoor je een deelbare link wilt maken.

4.

OPTIONEEL

 Om aangepaste [LaunchData](/docs/nl-nl/reference/engine/classes/Player#GetJoinData)  in te schakelen, zet je de schakelaar op Gebruik aangepaste LaunchData  en voer je een LaunchData  parameter in.

5.

Klik op Generate link .

De nieuwe deelbare link wordt onmiddellijk gegenereerd en is klaar om te worden gedeeld.

## [Maak een Marketplace link](#maak-een-marketplace-link)[](#maak-een-marketplace-link)

Je kunt alleen Marketplace links maken voor avatar-items en bundels die jij of je groep hebben gepubliceerd. Zowel betaalde als gratis items worden ondersteund. Voor groepsitems moet je lid zijn van de groep met de Configure avatar items  toestemming, en de deelbare link moet worden gemaakt vanuit het groepsaccount.

Om een Marketplace link te maken vanuit het tabblad Share Links:

1.

Ga in het [Creator Dashboard](https://create.roblox.com/dashboard/creations)  naar Creations , selecteer het tabblad Share Links  en selecteer vervolgens Marketplace Links .

2.

Klik op Create link .

3.

Selecteer het item waarvoor je een deelbare link wilt maken, of voer de asset ID of bundel ID in.

4.

Klik op Generate link .

Je kunt ook een Marketplace link maken vanuit je lijst met avatar-items. Open het menu van een item en selecteer de optie om een deelbare link te maken. Het dialoogvenster voor het maken van de link opent met dat item al geselecteerd.

De nieuwe deelbare link wordt onmiddellijk gegenereerd en is klaar om te worden gedeeld. Marketplace links verlopen niet. Je kunt een link op elk moment verwijderen uit de lijst met Marketplace Links . Verwijderde links openen nog steeds je item, maar registreren geen klikken of aankopen meer.

### [Waar Marketplace links gebruikers naartoe leiden](#waar-marketplace-links-gebruikers-naartoe-leiden)[](#waar-marketplace-links-gebruikers-naartoe-leiden)

-

Op desktop opent de link de pagina van je item op de Roblox-website.

-

Op mobiel met de Roblox-app geïnstalleerd, opent de link je item direct in de app.

-

Op mobiel zonder de app, vraagt de link gebruikers om Roblox te installeren en opent vervolgens je item.

Als je item verandert nadat je de link hebt gedeeld:

-

Niet te koop of uitverkocht : de link opent nog steeds de pagina van het item in de huidige niet te koop staat. Wanneer het item weer te koop is, kunnen gebruikers het opnieuw via de link kopen.

-

Gemodereerd of verwijderd : de link opent de Marketplace.

### [Marketplace link analytics](#marketplace-link-analytics)[](#marketplace-link-analytics)

Elke Marketplace link heeft een analytics-weergave in het Creator Dashboard die omvat:

-

Klikken : het totale aantal keren dat de link is geopend.

-

Unieke klikkers : het aantal verschillende gebruikers dat de link heeft geopend.

-

Aankopen : het aantal aankopen dat via de link is gedaan.

-

Uitgaven : het totale aantal Robux dat aan die aankopen is besteed.

-

Conversieratio : aankopen gedeeld door unieke klikkers.

Alleen geauthenticeerde gebruikers worden getraceerd. Je kunt tot 90 dagen aan dagelijkse gegevens bekijken en filteren op link. Analytics worden eenmaal per dag bijgewerkt, dus een nieuwe link kan ongeveer een dag duren om resultaten te tonen.
