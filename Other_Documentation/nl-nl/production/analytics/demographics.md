# Demografie

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Demografie  toont je de leeftijd, geslacht, land en taal van maandelijkse actieve gebruikers die je game spelen. Je kunt deze gegevens gebruiken om toekomstige contentupdates te prioriteren en merk-sponsoring veilig te stellen.

Om de demografische analyses van je game te bekijken:

1.

Navigeer naar je [Creations](https://create.roblox.com/dashboard/creations)  pagina op het Creator Dashboard  en selecteer je game.

2.

Selecteer in het Analytics  menu aan de linkerkant Demografie .

Je kunt analyses bekijken voor individuele of groepsbezit games. Om de laatste te bekijken, moet je [groepsmachtigingen voor analyses](/docs/nl-nl/production/analytics/analytics-dashboard#grant-group-permission)  hebben.

## [Bekijk demografie van het publiek](#bekijk-demografie-van-het-publiek)[](#bekijk-demografie-van-het-publiek)

Op de demografiepagina kun je een uitsplitsing van je maandelijkse actieve gebruikers in de volgende categorieën zien:

| Bron | | Beschrijving |
| --- | --- |
| Land | | Percentage van maandelijkse actieve gebruikers per land. Beweeg met de muis over een land of balk om de MAU's voor dat land te zien en klik op de downloadknop om gegevens voor alle landen te krijgen. |
| Geslacht | | Percentage van maandelijkse actieve gebruikers per geslacht. |
| Server frame rate | | Frames per seconde die door de server worden verwerkt. |
| Leeftijd | | Percentage van maandelijkse actieve gebruikers per leeftijd. |
| Top Talen | | De top 10 talen en hun percentages gesproken door maandelijkse actieve gebruikers. |

Om privacyredenen worden de groepen verborgen in de leeftijds- en geslachtsgrafieken als er minder dan 3 gebruikers in een van de leeftijds- of geslachtgroepen zijn.

## [Identificeer kansen voor het publiek](#identificeer-kansen-voor-het-publiek)[](#identificeer-kansen-voor-het-publiek)

Overweeg de volgende strategieën voor het gebruik van demografische gegevens om je game te verbeteren:

-

Prioriteer content waar je publiek mogelijk in geïnteresseerd is.

-

[Lokaliseer](/docs/nl-nl/production/localization)  je game metadata zoals titels met je publiek in gedachten.

-

Identificeer kansen om nieuwe doelgroepen aan te trekken.

-

Deel deze gegevens met potentiële merk-sponsors.
