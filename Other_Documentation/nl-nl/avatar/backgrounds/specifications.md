# Achtergrond specificaties

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Achtergronden voor avatars vereisen specifieke configuratiestandaarden om ervoor te zorgen dat alle achtergronden naar verwachting werken op het platform. Voordat je begint met het exporteren vanuit je 2D-bewerkingssoftware, controleer of je afbeelding voldoet aan de volgende bestands- en inhoudspecificaties en richtlijnen om correct weer te geven in de 3D-avatarviewer en op profielpagina's.

## [Bestandsvereisten](#bestandsvereisten)[](#bestandsvereisten)

| Vereiste | | Specificaties |
| --- | --- |
| Resolutie | | Exact 2560 x 1440 pixels |
| Kleur | | sRGB |
| Alpha-kanaal | | Geen, exporteer afgevlakte RGB zonder transparantie.

Veel kunsttools exporteren een .png  met een alpha-kanaal, zelfs wanneer de afbeelding geen transparante pixels bevat. Het is belangrijk om het alpha-kanaal in de exportinstellingen uit te schakelen, of de afbeelding af te vlakken en in plaats daarvan een .jpg  te exporteren.

 |
| Bestandsformaat | | .jpg , .png , .tga  of .bmp |
| Bestandsgrootte | | 20 MB of kleiner |

Roblox past een randvervaging toe zodat de achtergrond in de omliggende UI mengt, dus het is belangrijk om de afbeelding zonder je eigen vervaging te exporteren. Voor informatie over waar je details binnen het frame moet plaatsen, zie [Template zones](/docs/nl-nl/avatar/backgrounds#sjabloonzones) .
