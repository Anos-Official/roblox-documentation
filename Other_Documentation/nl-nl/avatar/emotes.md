# Emotes

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Emotes  zijn volledige lichaamsanimaties die een avatarpersonage kan uitvoeren om te communiceren en te vieren met anderen in een game, zoals gebaren, reacties en dansen. Terwijl Roblox een set standaard emotes voor elke avatar op het platform biedt, kun je je eigen emotes maken en verkopen op de Marketplace of binnen games.

Game-ontwikkelaars kunnen emotes binnen hun games openen en aanpassen. Voor meer informatie over dit proces, zie [character emotes](/docs/nl-nl/characters/emotes) .

## [Componenten](#componenten)[](#componenten)

Emotes bestaan uit een [Animation](/docs/nl-nl/reference/engine/classes/Animation)  object met de unieke [AnimationId](/docs/nl-nl/reference/engine/classes/Animation#AnimationId)  eigenschap ingesteld op de asset-ID van je animatievolgorde.

![](https://prod.docsiteassets.roblox.com/assets/avatar/avatar-emotes/Animation-Explorer.png) Animation  object in het Explorer-venster.

![](https://prod.docsiteassets.roblox.com/assets/avatar/avatar-emotes/Animation-Properties.png) AnimationId  eigenschap in het Properties-venster.

Alle emotes moeten voldoen aan de technische [emote-specificaties](/docs/nl-nl/avatar/emotes/specifications) , [Community Standards](https://en.help.roblox.com/hc/en-us/articles/203313410-Roblox-Community-Standards)  en [Marketplace-beleid](/docs/nl-nl/marketplace/marketplace-policy) .

## [Emotes maken](#emotes-maken)[](#emotes-maken)

Er zijn verschillende manieren waarop je emotes kunt maken met behulp van Studio of een derde-partij animatietool. Bekijk de volgende tabel voor specifieke workflows en bronnen:

| Animatieworkflow | | Beschrijving |
| --- | --- |
| Animatie-opname | | Gebruik de [Animatie-opname](/docs/nl-nl/animation/capture#lichaam)  tool van Studio om een volledige lichaamsvideo om te zetten in een keyframe-sequentie voor je emote. |
| Handmatige animatie met de Animatie-editor | | Gebruik de [Animatie-editor](/docs/nl-nl/animation/editor)  van Studio om handmatig een karakterrig te animeren. Voor een uitgebreide tutorial over het maken van een karakteranimatie, zie [Maak karakteranimaties](/docs/nl-nl/tutorials/use-case-tutorials/animation/create-an-animation) . |
| Derde-partij plug-ins | | Gebruik een derde-partij animatieplugin, zoals [Moon Animator](https://create.roblox.com/store/asset/4725618216/Moon-Animator-2) , om je animatie te genereren. |

Om je keyframe-sequentie om te zetten in een animatie die je kunt uploaden naar de Marketplace, zie [Import emotes - Genereer asset-ID](/docs/nl-nl/avatar/emotes/import#genereer-asset-id) .
