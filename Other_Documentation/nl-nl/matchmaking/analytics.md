# Matchmaking-analyse

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

Gebruik de statistieken van het matchmaking-analyse dashboard om de impact van individuele matchmaking-configuraties te analyseren en de signaalprestaties over verschillende tijdsperioden te monitoren.

## [Toegang tot het dashboard](#toegang-tot-het-dashboard)[](#toegang-tot-het-dashboard)

Om toegang te krijgen tot het matchmaking-analyse dashboard:

1.

Selecteer een game op het [Creator Dashboard](https://create.roblox.com/dashboard/creations) .

2.

Navigeer in de navigatie aan de linkerkant naar Configuraties  > Aangepaste matchmaking .

3.

Selecteer in de horizontale navigatie het tabblad Analyse .

## [Zie statistieken voor een specifieke plaats](#zie-statistieken-voor-een-specifieke-plaats)[](#zie-statistieken-voor-een-specifieke-plaats)

Het analyse dashboard bevat grafieken voor Roblox-signalen en aangepaste signalen. Als een matchmaking-configuratie één numeriek aangepast signaal en één categorisch aangepast signaal heeft, worden gegevens in zowel de numerieke als de categorische signaalgrafieken weergegeven. Als een configuratie twee van hetzelfde type aangepast signaal heeft (zoals twee numerieke of twee categorische), wordt slechts één van de grafieken gevuld met twee lijnen die gegevens voor beide vertegenwoordigen. Categoriale grafieken vertegenwoordigen een gelijkenisratio, terwijl numerieke grafieken het verschil vertegenwoordigen.

Om matchmaking-statistieken voor een specifieke plaats in je game te zien:

1.

Klik in het tabblad Analyse  op de dropdown Datumbereik  en selecteer een datumbereik tussen de vorige dag en de laatste 90 dagen.

2.

Klik op de dropdown Plaats  en selecteer de plaats waarvoor je statistieken wilt zien. De Huidige Configuratie  wordt bijgewerkt met de naam van de matchmaking-configuratie die is toegepast op de door jou geselecteerde plaats.

 ![Matchmaking-analyse grafieken voor verschillende ratio's.](https://prod.docsiteassets.roblox.com/assets/matchmaking/MatchmakingAnalytics.png)

Als de geselecteerde plaats geen aangepaste matchmaking-configuratie heeft, toont het dashboard statistieken voor de standaard Roblox matchmaking-configuratie.

## [Filteren op percentielwaarden](#filteren-op-percentielwaarden)[](#filteren-op-percentielwaarden)

In het tabblad Analyse  selecteer je het menu Filteren op  om signaalgrafieken te wisselen tussen gemiddelden en de volgende percentielwaarden:

-

P90  om te filteren op het aantal waarden dat binnen het 90e percentiel valt.

-

P10  om te filteren op het aantal waarden dat binnen het 10e percentiel valt.

-

P50  om te filteren op de mediaan, waarbij de helft van alle waarden erboven en de helft eronder valt.

De filter is van toepassing op alle signaalgrafieken.

Percentielwaarden worden van klein naar groot berekend, dus voor statistieken waarbij lagere nummers beter zijn, vertegenwoordigt P10 de "beste situatie" en P90 de "slechtste situatie" in plaats van andersom.

## [Signaalgrafieken](#signaalgrafieken)[](#signaalgrafieken)

Het tabblad Analyse  bevat de volgende signaalgrafieken:

| Grafiek | | Beschrijving |
| --- | --- |
| Bezettingsratio | | De gemiddelde/P10/P50/P90 bezettingsratio van de gekozen server. |
| Gemiddelde voor Voorkeurs Speler Match Ratio | | Het gemiddelde percentage van matchmaking-verzoeken dat de toetredende speler aan een server met voorkeurs spelers koppelt. |
| Leeftijdsverschil | | De gemiddelde/P10/P50/P90 waarde van het leeftijdsverschil tussen de toetredende speler en de gemiddelde leeftijd van alle spelers in de gekozen server. |
| Gemeenschappelijke Taal Ratio | | De gemiddelde/P10/P50/P90 gemeenschappelijke taalratio van de gekozen server. De gemeenschappelijke taal is de taal die gedeeld wordt tussen bestaande spelers in de server en de toetredende speler. |
| Schatting Ping | | De gemiddelde/P10/P50/P90 geschatte pingwaarde van de gekozen server. |
| Stemchat Ratio | | De gemiddelde/P10/P50/P90 bezettingsratio van spelers met ingeschakelde stemchat in de gekozen server. |
| Gemeenschappelijk Apparaat Ratio | | De gemiddelde/P10/P50/P90 gemeenschappelijke apparaat ratio van de gekozen server. Het gemeenschappelijke apparaat is het apparaattype dat gedeeld wordt tussen bestaande spelers in de server en de toetredende speler. |
| Speelgeschiedenis Verschil | | De gemiddelde/P10/P50/P90 waarde van het verschil in speelgeschiedenis tussen de toetredende speler en de gemiddelde speelgeschiedenis van alle spelers in de gekozen server. |
| Numeriek Aangepast Signaal Verschil | | De gemiddelde/P10/P50/P90 waarde van het numerieke signaalverschil tussen de toetredende speler en het servergemiddelde. |
| Categorisch Aangepast Signaal Gelijkenis Ratio | | De gemiddelde/P10/P50/P90 categorische signaal gelijkenisratio tussen de toetredende speler en het servergemiddelde. |
