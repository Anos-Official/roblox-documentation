# Woordenlijst

Nederlands

* Deze inhoud is vertaald met behulp van AI (bèta) en kan fouten bevatten. Klik [hier]  om deze pagina in het Engels te bekijken.

| Term | | Beschrijving |
| --- | --- |
| Intellectuele eigendom (IP) | | Een IP vertegenwoordigt een franchise of een verzameling creatieve werken die beschikbaar kunnen worden gesteld voor licentieverlening. |
| Rechthebbende | | De entiteit die de licentiegever is voor het creatieve werk, merk of franchise die wordt geregistreerd. |
| IP-bibliotheek | | Een lijst van al jouw IP-families; een bibliotheek van tekst en afbeeldingen die Roblox gebruikt om de IP te identificeren. |
| IP-familie | | De entiteit van de IP die wordt geregistreerd. Bijvoorbeeld, "Polly Pocket" of "Blue Lock".
 We raden aan om slechts één IP-familie per IP te creëren. |
| Licentiecatalogus | | De volledige catalogus van IP's op de Creator Hub die makers kunnen aanvragen om in hun games te gebruiken. |
| IP-vermelding | | Een vermelding die de IP en alle beschikbare licenties uitlegt aan makers die willen aanvragen om die IP te gebruiken. |
| IP-licentie | | Een set van voorwaarden die definieert hoe een bepaalde IP door makers kan worden gebruikt om games op Roblox te bouwen. Rechthebbenden kunnen verschillende licenties per IP-familie creëren (bijvoorbeeld, "Polly Pocket Volledige Licentie", "20% Omzetdeel Licentie", of "Minimale Volwassenheidslicentie"). |
| Licentieshowcase | | Een optionele set van maximaal 10 games die een rechthebbende benadrukt op de details pagina van een live licentie. Showcase-games moeten al een overeenkomst hebben met die licentie en verschijnen in een carrousel onder Over  in de licentiecatalogus. |
| Primaire sleutelwoord | | De officiële naam van jouw IP. Bijvoorbeeld, "Polly Pocket". |
| Secundaire sleutelwoorden | | Een lijst van woorden of zinnen die personages, objecten, plaatsen of elementen vertegenwoordigen die gerelateerd zijn aan jouw IP. Bijvoorbeeld, "Polly", "Shani", en "Pollyville". |
| Private licentie | | Een private licentie is alleen beschikbaar voor makers die de rechthebbende rechtstreeks benadert. |
| Openbare licentie | | Een openbare licentie is zichtbaar voor alle makers op de licentiepagina. |
| Omzetdeelpercentage | | Het omzetdeel dat rechthebbenden ontvangen van games die hun IP gebruiken. Dit is een percentage van de bruto Robux die de maker van de game verdient.
 Omzetdeel geldt alleen voor:

-

De bruto-omzet van een game, wat de Robux is die na platformkosten is verdiend.

-

Verdiensten vanaf het moment dat een licentieovereenkomst actief wordt.

 |
| Timing van omzetdeel | | Een van:

-

Monetize bij activatie , wat betekent dat het omzetdeel wordt toegepast op het moment dat de overeenkomst tussen de rechthebbende en de maker van de game actief wordt.

-

Monetize later , wat rechthebbenden toestaat om het omzetdeel op een later tijdstip in te schakelen.

 |
| Standaardaanbieding | | Een licentieaanbieding die een rechthebbende naar een gematchte game stuurt. De overeenkomst wordt actief wanneer de maker deze accepteert, of automatisch na 14 dagen als de maker deze niet betwist. |
| Voorwaardelijke aanbieding | | Een licentieaanbieding die een rechthebbende stuurt wanneer ze willen samenwerken met een maker, maar de game moet eerst voldoen aan specifieke inhoudsnormen. De rechthebbende geeft feedback over de vereiste wijzigingen. De maker heeft 14 dagen om de wijzigingen aan te brengen en deze als voltooid te markeren. De overeenkomst wordt alleen actief nadat de rechthebbende deze wijzigingen heeft beoordeeld en goedgekeurd. Voorwaardelijke aanbiedingen worden niet automatisch geactiveerd. |
| Voorwaardelijke goedkeuring | | Wanneer een rechthebbende reageert op een verzoek van een maker voor een eeuwigdurende licentie door wijzigingen te vereisen voordat de overeenkomst kan worden geactiveerd. De maker heeft 14 dagen om de wijzigingen aan te brengen en deze als voltooid te markeren. Betwisting is niet beschikbaar voor voorwaardelijke goedkeuringen van door de maker ingediende verzoeken; makers kunnen in plaats daarvan het verzoek annuleren. |
