# Export

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/art/accessories/creating/exporting.md)

It's important to follow the Blender export settings to ensure a Studio-compatible .fbx  file. Before exporting your file, ensure that you've removed extra objects, such as lights, cameras, or mannequins, and applied or removed any active modifiers.

To export your file from Blender:

1.

In the Outliner, unhide all objects, make them selectable, then select everything in your project.

 ![](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/Blender-Export-Settings-0.png)

2.

In the topbar, click File  > Export  > FBX (.fbx) . The Blender File View  window displays.

3.

On the right-hand side, set Path Mode  to Copy , then toggle the Embed Textures  button.

 ![](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/Blender-Export-Settings-1.png)

4.

In the Include  section, enable Selected Objects .

5.

In the Transform  section, set Apply Scalings  to FBX Unit Scale . If you run into scaling issues on import, see [Blender FBX scaling](/docs/art/blender#adjust-scale-fbx)  for alternative approaches.

 ![](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/Blender-Export-Settings-5.png)

6.

In the Armature  section, disable Add Leaf Bones .

 ![](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/Blender-Export-Settings-3.png)

7.

Disable Bake Animation .

 ![](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/Blender-Export-Settings-4.png)

8.

Click the Export FBX  button.

You've completed the exporting section of this tutorial. If desired, download a [reference sample](https://prod.docsiteassets.roblox.com/assets/art/accessories/creating/Long_Sleeve_Export.fbx)  of this exported file for comparison. You can use this reference in the next importing step.
