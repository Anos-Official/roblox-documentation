# Coding fundamentals

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/tutorials/fundamentals/coding-1/coding-fundamentals.md)

### [Series description](#series-description)[](#series-description)

Start coding on Roblox with this easy-to-follow series covering the fundamentals of how to use the programming language Luau. These courses are perfect for those new to coding or just starting with Luau. Each course centers around a foundational computer science principle, and features individual lessons with step-by-step tutorials you can use to create your own games on Roblox.

Before beginning this course, the reader should have basic knowledge of Roblox Studio, as demonstrated in the [Studio](/docs/tutorials/curriculums/studio)  and [Building](/docs/tutorials/curriculums/building)  lesson.

### [Series contents](#series-contents)[](#series-contents)

| Series | | Description |
| --- | --- |
| [Variables and objects](/docs/tutorials/fundamentals/coding-1/landing) | |  Create your first script and start making things happen with code. These tutorials cover variables, data types, and properties. |
| [Functions and events](/docs/tutorials/fundamentals/coding-2/functions-and-events) | | Use functions to create chunks of code that run only when you tell it. Connect your code to in-world events to create interactive objects like traps or bridges. |
| [Conditionals](/docs/tutorials/fundamentals/coding-3/landing) | | Conditionals use the coding pattern of "if this happens then do that." Apply this pattern to check if the time is right to unlock power ups for your players. |
| [Loops](/docs/tutorials/fundamentals/coding-4/landing) | | Learn how to repeat code a certain amount of time or make it run forever using for and while loops. Practice using these loop types to code timed bridges and flashing lights. |
| [Dictionaries and arrays](/docs/tutorials/fundamentals/coding-5/landing) | | Learn how to store a lot of data in a single variable using tables and arrays. Data structures such as these can store large data sets like a player's inventory. |
| [Organize code](/docs/tutorials/fundamentals/coding-6/landing) | | Take your code organization a step further and learn about module scripts, a unique type of script that can interact with other scripts in Luau. |
