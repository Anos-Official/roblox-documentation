# Learn about Studio

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/tutorials/curriculums/studio/index.md)

![](https://prod.docsiteassets.roblox.com/assets/tutorials/landing/StudioThumbnail.png)

This tutorial acts as an introduction to Roblox Studio, a free application on Windows or Mac that has everything you need to start creating games on the Roblox platform! As you follow each chapter, you will learn how to login into Studio, then navigate its core user interface windows.

This lesson is intended for readers who are brand new  to working in Studio. If you are already familiar with Studio, try another beginner lesson plan or jump straight to [building your first game](/docs/tutorials/curriculums/core) .

## [Course contents](#course-contents)[](#course-contents)

Chapter 1 - Create Roblox account

Learn how to [create a free account](/docs/tutorials/curriculums/studio/create-account)  on Roblox so that you can login to Studio.

Chapter 2 - Install Roblox Studio

Learn how to [install Studio](/docs/tutorials/curriculums/studio/install-studio)  on your computer.

Chapter 3 - Explore Studio UI

Learn about the [fundamental windows](/docs/tutorials/curriculums/studio/explore-ui)  you need to know to navigate Studio.

Chapter 4 - Next steps

Learn where you can [find more tutorials](/docs/tutorials/curriculums/studio/next-steps)  about creating games.
