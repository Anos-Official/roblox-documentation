# Intro to animation

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/tutorials/curriculums/animator/index.md)

![](https://prod.docsiteassets.roblox.com/assets/tutorials/landing/AnimationThumbnail.png)

Using the [Island of Move](https://www.roblox.com/games/5306359293/Island-of-Move)  sample as a guide, this tutorial acts as an introduction to creating animations in Roblox Studio. As you follow each chapter, you will learn how to create keyframes for various poses, then loop them into a swimming animation that you can reuse in any game.

This lesson is intended for readers who are brand new  to creating animations and working in Studio. If you are familiar with both, try another beginner lesson plan or jump straight to [building your first game](/docs/tutorials/curriculums/core) .

If you don't have a Roblox account, Studio active on your device, or familiarity with Studio's UI, see the [Studio lesson](/docs/tutorials/curriculums/studio) .

## [Course contents](#course-contents)[](#course-contents)

Chapter 1 - Get started

Learn how to [open and customize](/docs/tutorials/curriculums/animator/get-started)  the template's workspace so that you can work with a poseable figure.

Chapter 2 - Work with the Animation Editor

Learn how to [use the Animation Editor](/docs/tutorials/curriculums/animator/work-with-the-animation-editor)  to create keyframes for different poses of an animation.

Chapter 3 - Play your animation

Learn how to [export and replace](/docs/tutorials/curriculums/animator/play-your-animation)  the character's default run animation with your new animation.

Chapter 4 - Test and save

Learn how to [playtest your animation](/docs/tutorials/curriculums/animator/test-and-save)  and publish your work to Roblox.

Chapter 5 - Next steps

Learn where you can [find more tutorials](/docs/tutorials/curriculums/animator/next-steps)  about animating characters for games.
