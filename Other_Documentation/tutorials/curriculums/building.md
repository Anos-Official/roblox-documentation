# Intro to building

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/tutorials/curriculums/building/index.md)

![](https://prod.docsiteassets.roblox.com/assets/tutorials/landing/BuildingThumbnail.png)

Using the [Classic Obby](https://www.roblox.com/games/203812057/Classic-Obby)  template as a guide, this tutorial acts as an introduction to building in Roblox Studio using basic parts and AI Assistant. As you follow each chapter, you will learn how to create an obstacle course (obby) where players jump across platforms and avoid obstacles until they reach the final platform.

This lesson is intended for readers who are brand new  to building with parts and working in Studio. If you are familiar with both, try another beginner lesson plan or jump straight to [building your first game](/docs/tutorials/curriculums/core) .

If you don't have a Roblox account, Studio active on your device, or familiarity with Studio's UI, see the [Studio lesson](/docs/tutorials/curriculums/studio) .

## [Course contents](#course-contents)[](#course-contents)

Chapter 1 - Get started

Learn how to [open and customize](/docs/tutorials/curriculums/building/get-started)  the template's workspace so that you can focus on building your obby.

Chapter 2 - Work with parts

Learn how to [create and design platforms](/docs/tutorials/curriculums/building/work-with-parts)  for your obby using basic part shapes.

Chapter 3 - Code with AI Assistant

Learn how to [modify part behavior](/docs/tutorials/curriculums/building/code-with-assistant)  with code from AI Assistant.

Chapter 4 - Test and save

Learn how to [playtest your obby](/docs/tutorials/curriculums/building/test-and-save)  and publish your work to Roblox.

Chapter 5 - Next steps

Learn where you can [find more tutorials](/docs/tutorials/curriculums/building/next-steps)  about building games with parts and meshes.
