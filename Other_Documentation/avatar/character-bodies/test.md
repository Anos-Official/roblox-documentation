# Test character bodies

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/avatar/character-bodies/test.md)

To ensure your character bodies for avatars can move, interact with objects in the 3D space, and wear cosmetics, clothing, and accessories, it's important to periodically test their components in both your third-party modeling tool and in Studio as you iterate on their design. By testing often, you can save yourself a lot of time in having to rework time-intensive processes like rigging, skinning, and caging.

Whether you are using a [template character](/docs/avatar/resources#templates)  or [project file](/docs/avatar/resources#project-files)  as a basis for your character body, reference the following tables for common tests and resources you can use throughout the creation process to comprehensively quality check each component of your character models.

Blender Tests Studio Tests

You can apply the following workflows with any 3D modeling software, though certain interfaces and instructions may differ between platforms. For more information, see [Test character bodies in Blender](/docs/avatar/character-bodies/test-blender) .

 |
