# Feature packages

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/resources/feature-packages/index.md)

Feature packages are fully functional, customizable features that you can drag and drop directly into your game. Each feature package comes with:

-

Functional back-end code for minimal engineering work

-

Default UI components that you can customize to fit your unique aesthetics

-

Built-in game design and UI/UX best practices

-

Funnel analytics and insights

You can use feature packages to add new functionality and gameplay features to your games, improve your game's key metrics, and contribute to sustainable [live operations](/docs/production/game-design/liveops-essentials)  (LiveOps).

## Bundles

The Bundles  feature package offers out-of-the-box functionality to sell collections of items to players at a discount.

![](https://prod.docsiteassets.roblox.com/assets/resources/feature-packages/Bundles/Bundles-Intro.png)

##### Define currencies

Register your own in-game currency for players to purchase items.

##### Choose items

Select the items you want to bundle at a discount.

##### Customize prompts

Create bundle prompts that anticipate player needs at key points of your game.

[Start creating](/docs/resources/feature-packages/bundles)

## Missions

The Missions  feature package offers out-of-the-box functionality to create missions that players can complete to achieve rewards and progress in your game.

![](https://prod.docsiteassets.roblox.com/assets/resources/feature-packages/Missions/Missions-Intro.png)

##### Define tasks

Determine what players need to do to complete a mission.

##### Track progress

Add logic that updates task progress as players work on set objectives.

##### Customize menus

Create unique UI that matches the aesthetics of your games.

[Start creating](/docs/resources/feature-packages/missions)

## Season passes

The Season Passes  feature package offers out-of-the-box functionality to create quests that players can complete to earn rewards during a pre-defined period of time.

![](https://prod.docsiteassets.roblox.com/assets/resources/feature-packages/Season-Passes/Season-Passes-Intro.png)

##### Define quests

Determine what players need to do to complete a quest.

##### Track progress

Add logic that updates quest progress as players work on set objectives.

##### Customize rewards

Create game-specific rewards to encourage players to progress through a season.

[Start creating](/docs/resources/feature-packages/season-passes)

## Engagement rewards

The Engagement Rewards  feature package is a customizable framework for offering in-game rewards for certain player activities, such as daily logins, login streaks, and time played.

![](https://prod.docsiteassets.roblox.com/assets/resources/feature-packages/engagement/rewards.jpg)

##### Initialize the package

Set up the core function to give players rewards.

##### Add rewards

Create rewards, provide thumbnails, and set reward criteria.

##### Customize the UI

Match the user interface to your game.

[Start creating](/docs/resources/feature-packages/engagement-rewards)
