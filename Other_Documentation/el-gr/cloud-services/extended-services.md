# Επεκτεμένες Υπηρεσίες

English

* This content is translated using AI (Beta) and may contain errors. To view this page in English, click [here] .

Οι Επεκτεμένες Υπηρεσίες είναι μια λύση που σας επιτρέπει να διαχειρίζεστε τη χρήση υπηρεσιών και την πληρωμή πέρα από τα προεπιλεγμένα όρια του Roblox. Περιλαμβάνει αποθηκευτικούς χώρους δεδομένων, αποθηκευτικούς χώρους μνήμης, μετατροπή κειμένου σε ομιλία, μετατροπή ομιλίας σε κείμενο και υπολογιστική ισχύ.

## [Απαιτήσεις επιλεξιμότητας](#απαιτήσεις-επιλεξιμότητας)[](#απαιτήσεις-επιλεξιμότητας)

Για να χρησιμοποιήσετε τις Επεκτεμένες Υπηρεσίες, ο λογαριασμός σας στο Roblox πρέπει να:

-

Είναι [επαληθευμένος με ID](/docs/en-us/production/publishing/account-verification#verify-through-government-id)  και άνω των 18 ετών.

-

Βρίσκεται σε [υποστηριζόμενη χώρα](#%CF%85%CF%80%CE%BF%CF%83%CF%84%CE%B7%CF%81%CE%B9%CE%B6%CF%8C%CE%BC%CE%B5%CE%BD%CE%B5%CF%82-%CF%87%CF%8E%CF%81%CE%B5%CF%82) .

-

Έχει μια έγκυρη διεύθυνση email συνδεδεμένη με αυτόν.

-

Να μην είναι αυτή τη στιγμή αποκλεισμένος ή υπό επιτήρηση.

-

Να αποδεχθεί και να συμμορφωθεί με τους [όρους υπηρεσίας](https://en.help.roblox.com/hc/articles/37967848292500) .

Για λογαριασμούς ομάδων, μόνο ο ιδιοκτήτης της ομάδας χρειάζεται να πληροί τις απαιτήσεις επιλεξιμότητας.

## [Ξεκλειδώστε τις Επεκτεμένες Υπηρεσίες](#ξεκλειδώστε-τις-επεκτεμένες-υπηρεσίες)[](#ξεκλειδώστε-τις-επεκτεμένες-υπηρεσίες)

Εάν πληροίτε όλες τις [απαιτήσεις επιλεξιμότητας](#%CE%B1%CF%80%CE%B1%CE%B9%CF%84%CE%AE%CF%83%CE%B5%CE%B9%CF%82-%CE%B5%CF%80%CE%B9%CE%BB%CE%B5%CE%BE%CE%B9%CE%BC%CF%8C%CF%84%CE%B7%CF%84%CE%B1%CF%82) , μπορείτε να ολοκληρώσετε τη ρύθμιση των Επεκτεμένων Υπηρεσιών εισάγοντας τα στοιχεία του λογαριασμού σας και τις πληροφορίες πληρωμής. Για παιχνίδια που ανήκουν σε ομάδες, μόνο ο ιδιοκτήτης της ομάδας μπορεί να ξεκλειδώσει τις Επεκτεμένες Υπηρεσίες και να ενσωματώσει το παιχνίδι σε αυτές.

Για να ξεκλειδώσετε και να χρησιμοποιήσετε τις Επεκτεμένες Υπηρεσίες:

1.

Στον [Πίνακα Δημιουργών](https://create.roblox.com/dashboard/creations) , μεταβείτε στην Δημιουργίες  και επιλέξτε ένα παιχνίδι.

2.

Μεταβείτε στις Επεκτεμένες Υπηρεσίες .

3.

Εάν δεν έχετε εισάγει ακόμη τα στοιχεία του λογαριασμού σας και τις πληροφορίες πληρωμής, κάντε κλικ στο Προσθήκη ελλειπουσών πληροφοριών  στην επάνω μπάρα.

1.

Εισάγετε τις πληροφορίες του λογαριασμού σας. Τα πεδία Τύπος λογαριασμού , Τύπος ΑΦΜ  και ΑΦΜ  είναι προαιρετικά.

-

Μπορείτε επίσης να μεταβείτε στις Οικονομικές  ⟩ Πληροφορίες Λογαριασμού  στην ενότητα Επεκτεμένες Υπηρεσίες  για να διαχειριστείτε τις πληροφορίες του λογαριασμού σας. Δεν χρειάζεται να ενημερώσετε τίποτα άλλο σε αυτή τη σελίδα.

2.

Κάντε κλικ στο Επόμενο .

3.

Εισάγετε μια μέθοδο πληρωμής. Μπορείτε να εισάγετε μια νέα μέθοδο πληρωμής ή να επιλέξετε από τις διαθέσιμες επιλογές πληρωμής που είναι ήδη συνδεδεμένες με τον λογαριασμό σας στο Roblox.

-

Μπορείτε επίσης να μεταβείτε στις Οικονομικές  ⟩ Πληρωμές  για να προσθέσετε νέες μεθόδους πληρωμής ή να μεταβείτε στις Οικονομικές  ⟩ Χρέωση  για να ορίσετε μια νέα προεπιλεγμένη μέθοδο πληρωμής.

4.

Κάντε κλικ στο Αποθήκευση .

## [Ενεργοποίηση υπηρεσίας](#ενεργοποίηση-υπηρεσίας)[](#ενεργοποίηση-υπηρεσίας)

Για να ενεργοποιήσετε μια υπηρεσία:

1.

Μεταβείτε στις Επεκτεμένες Υπηρεσίες .

2.

Ενεργοποιήστε την υπηρεσία που θέλετε να ενεργοποιήσετε.

3.

Εισάγετε έναν μηνιαίο προϋπολογισμό για κάθε σχετικό πόρο κάτω από την υπηρεσία. Ο ελάχιστος μηνιαίος προϋπολογισμός που μπορείτε να ορίσετε είναι $0.50 USD.

Η μέθοδος πληρωμής σας χρεώνεται είτε στο τέλος του μήνα όταν δημιουργείται ένας λογαριασμός, είτε όταν η χρήση σας φτάσει τα $10 USD, όποιο από τα δύο συμβεί πρώτο.

Μπορείτε να αυξήσετε ή να μειώσετε τον μηνιαίο προϋπολογισμό μιας υπηρεσίας οποιαδήποτε στιγμή. Η υπηρεσία σας περιορίζεται αυτόματα εάν μειώσετε τον προϋπολογισμό σας σε ποσό κάτω από τη χρήση σας μέχρι σήμερα, ή εάν υπερβείτε τον προϋπολογισμό που έχετε ορίσει.

Το Roblox σας ειδοποιεί μέσω email όταν η χρήση σας φτάσει το 80% του προϋπολογισμού σας, και στη συνέχεια ξανά όταν φτάσει το 100%.

### [Επεκτεμένες Υπηρεσίες για Υπολογιστική Ικανότητα](#επεκτεμένες-υπηρεσίες-για-υπολογιστική-ικανότητα)[](#επεκτεμένες-υπηρεσίες-για-υπολογιστική-ικανότητα)

Κάθε διακομιστής παιχνιδιού λαμβάνει μια προεπιλεγμένη ποσότητα CPU, η οποία αυξάνεται με κάθε παίκτη που συμμετέχει. Οι Επεκτεμένες Υπηρεσίες για Υπολογιστική Ικανότητα  διπλασιάζουν περισσότερο την CPU ανά παίκτη που λαμβάνουν οι διακομιστές του παιχνιδιού σας.

Η συντριπτική πλειοψηφία των παιχνιδιών στο Roblox δεν βλέπει κανένα όφελος από αυτή την υπηρεσία, αλλά τα παιχνίδια με βαριά φυσική πλευρά του διακομιστή ή που κάνουν εκτενή χρήση της [εξουσίας του διακομιστή](/docs/en-us/projects/server-authority)  χτυπούν τα υπάρχοντα όρια. Για να δείτε αν το παιχνίδι σας μπορεί να επωφεληθεί από τις Επεκτεμένες Υπηρεσίες για Υπολογιστική Ικανότητα :

-

Ελέγξτε τον [ρυθμό καρδιάς του διακομιστή](/docs/en-us/performance-optimization/identify#server-compute)  για επίμονες πτώσεις κάτω από 60 FPS.

-

Εξετάστε τη χρήση πυρήνα CPU στον [Πίνακα Απόδοσης](/docs/en-us/production/analytics/performance#server-charts) .

Πριν πληρώσετε για περισσότερη CPU, προσπαθήστε να [μειώσετε τη δουλειά που κάνουν οι διακομιστές σας](/docs/en-us/performance-optimization/improve) .

## [Διαχείριση χρέωσης](#διαχείριση-χρέωσης)[](#διαχείριση-χρέωσης)

Για να αποκτήσετε πρόσβαση στον πίνακα χρέωσης των Επεκτεμένων Υπηρεσιών:

1.

Μεταβείτε στις Οικονομικές  ⟩ Χρέωση .

2.

Επιλέξτε την καρτέλα Υπηρεσίες Cloud  για να εμφανίσετε τα εξής:

-

Το εκκρεμές σας υπόλοιπο, συμπεριλαμβανομένου του κόστους μέχρι σήμερα

-

Το ιστορικό χρέωσης σας, συμπεριλαμβανομένης της δραστηριότητας χρέωσης των Επεκτεμένων Υπηρεσιών σε όλα τα παιχνίδια σας

Για μια λεπτομερή ανάλυση των τρεχουσών εκκρεμών χρεώσεων, κάντε κλικ στο Δείτε Λεπτομέρειες  δίπλα στη μέθοδο πληρωμής σας. Για μια λεπτομερή τιμολόγηση ενός προηγούμενου λογαριασμού, κάντε κλικ στο Δείτε Λογαριασμό  κάτω από το Ιστορικό Χρέωσης .

| [Υπολογιστική Ικανότητα ](https://create.roblox.com/docs/production/analytics/performance) | | Πυρήνες CPU | | Πρώτες 100K ώρες παιχνιδιού ανά μήνα χωρίς χρέωση (όταν εγγραφείτε στις Επεκτεμένες Υπηρεσίες για Υπολογιστική Ικανότητα) | | $0.001 / ώρα παιχνιδιού² |

 ¹ GB ανά ώρα = η κατανάλωση αποθήκευσης πολλαπλασιασμένη με την ποσότητα χρόνου. Για παράδειγμα, 100 GB ώρες μπορεί να ισοδυναμούν με "100 GB × 1 ώρα" ή "200 GB × 0.5 ώρες".  ² Οι Επεκτεμένες Υπηρεσίες για Υπολογιστική Ικανότητα χρεώνονται με βάση το πόσο καιρό παραμένει ενεργοποιημένη η δυνατότητα, μετρημένη σε λεπτά παιχνιδιού. Επειδή η ενεργοποίηση της δυνατότητας διατηρεί επιπλέον υπολογιστική ικανότητα για το παιχνίδι σας, οι χρεώσεις ισχύουν όποτε η δυνατότητα είναι ενεργή, ακόμη και αν η επιπλέον υπολογιστική ικανότητα δεν καταναλώνεται πλήρως. Οι ώρες παιχνιδιού υπολογίζονται ως το άθροισμα όλων των διαρκειών συνεδρίας παικτών. Για παράδειγμα, εάν 10.000 χρήστες παίξουν ο καθένας για 1 ώρα, αυτό ισοδυναμεί με 10.000 ώρες παιχνιδιού, με αποτέλεσμα $10 σε χρεώσεις πέρα από την περιλαμβανόμενη μηνιαία επιδότηση των 100.000 ωρών παιχνιδιού. Αυτά τα όρια και οι τιμές ισχύουν μόνο για παιχνίδια που έχουν εγγραφεί στις Επεκτεμένες Υπηρεσίες για Υπολογιστική Ικανότητα. Παιχνίδια που δεν εγγράφονται συνεχίζουν να λαμβάνουν απεριόριστες ώρες παιχνιδιού υπό τα τρέχοντα προεπιλεγμένα όρια χωρίς επιπλέον χρέωση.
