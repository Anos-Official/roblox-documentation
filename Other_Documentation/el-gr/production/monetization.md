# Μονοποίηση

English

* This content is translated using AI (Beta) and may contain errors. To view this page in English, click [here] .

Η μονοποίηση είναι μέρος της συνολικής δομής του Roblox για την παροχή αξίας στους δημιουργούς. Υπάρχουν αρκετές διαφορετικές προσεγγίσεις για να μονοποιήσετε το περιεχόμενό σας, συμπεριλαμβανομένης της χρήσης [συνδρομών](#%CF%83%CF%85%CE%BD%CE%B4%CF%81%CE%BF%CE%BC%CE%AD%CF%82) , της χρέωσης ενός τέλους πρόσβασης σε [Robux](#%CF%80%CE%BB%CE%B7%CF%81%CF%89%CE%BC%CE%AD%CE%BD%CE%B7-%CF%80%CF%81%CF%8C%CF%83%CE%B2%CE%B1%CF%83%CE%B7-%CF%83%CE%B5-robux)  ή [τοπικό νόμισμα](#%CF%80%CE%BB%CE%B7%CF%81%CF%89%CE%BC%CE%AD%CE%BD%CE%B7-%CF%80%CF%81%CF%8C%CF%83%CE%B2%CE%B1%CF%83%CE%B7-%CF%83%CE%B5-%CF%84%CE%BF%CF%80%CE%B9%CE%BA%CF%8C-%CE%BD%CF%8C%CE%BC%CE%B9%CF%83%CE%BC%CE%B1) , της παροχής [αντικειμένων ή ικανοτήτων που μπορούν να αγοράσουν οι χρήστες](#%CF%80%CF%81%CE%BF%CF%8A%CF%8C%CE%BD%CF%84%CE%B1-%CF%80%CF%81%CE%BF%CE%B3%CF%81%CE%B1%CE%BC%CE%BC%CE%B1%CF%84%CE%B9%CF%83%CF%84%CF%8E%CE%BD) , της προσφοράς [ιδιωτικών διακομιστών](#%CE%B9%CE%B4%CE%B9%CF%89%CF%84%CE%B9%CE%BA%CE%BF%CE%AF-%CE%B4%CE%B9%CE%B1%CE%BA%CE%BF%CE%BC%CE%B9%CF%83%CF%84%CE%AD%CF%82)  για να παίζουν οι χρήστες μόνο με φίλους, και της [πώλησης μοντέλων και προσθέτων](/docs/en-us/production/creator-store#distribute-and-sell-assets)  σε άλλους δημιουργούς στο Creator Store.

Εάν επιλέξετε να προσφέρετε περιεχόμενο προς αγορά, το Roblox δεν καταγράφει αυτόματα πληροφορίες προϊόντων ή αγορών. Για να αποφύγετε την απώλεια δεδομένων, πρέπει να αποθηκεύσετε προσεκτικά αυτά τα δεδομένα χρησιμοποιώντας το [DataStoreService](/docs/en-us/reference/engine/classes/DataStoreService)  ή άλλη υπηρεσία αποθήκευσης δεδομένων που φιλοξενείται εκτός του Roblox.

Για μια σε βάθος ματιά στο σχεδιασμό βέλτιστων στρατηγικών μονοποίησης για την εμπειρία σας, δείτε τα [θεμέλια μονοποίησης](/docs/en-us/production/game-design/monetization-foundations) .

## [Στρατηγικές μονοποίησης](#στρατηγικές-μονοποίησης)[](#στρατηγικές-μονοποίησης)

Να είστε προσεκτικοί με τις μεθόδους μονοποίησης που εισάγετε στο παιχνίδι σας, καθώς οι χρήστες μας είναι πιθανό να καταψηφίσουν  το παιχνίδι σας αν δεν εγκρίνουν τις στρατηγικές σας. Επίσης, όλοι οι προγραμματιστές πρέπει να είναι διαφανείς με οποιαδήποτε [τυχαία μονοποίηση](/docs/en-us/production/monetization/paid-random-items)  και να χρησιμοποιούν αυτές τις μηχανικές υπεύθυνα.

Ορισμένες δημοφιλείς στρατηγικές μονοποίησης για παιχνίδια δωρεάν παιχνιδιού σε άλλες πλατφόρμες δεν συνιστώνται για το Roblox. Για παράδειγμα, οι μηχανισμοί ραντεβού και οι χρονομετρητές που μπορούν να αφαιρεθούν ή να προχωρήσουν μπορεί να λειτουργούν καλά σε άλλες πλατφόρμες, αλλά αυτοί οι μηχανισμοί είναι μη δημοφιλείς στους χρήστες του Roblox, οι οποίοι έχουν πρόβλημα με τη διασκέδασή τους να έρχεται σε πρόωρο τέλος.

Οι παρακάτω προτάσεις βέλτιστων πρακτικών είναι δημοφιλείς μεταξύ κορυφαίων προγραμματιστών για την προσαρμογή στρατηγικών μονοποίησης στην πλατφόρμα και το κοινό του Roblox.

Σημειώστε ότι εφαρμόζοντας αυτές τις τεχνικές και τις παρατηρήσεις, δεν εγγυάστε ότι θα μπορέσετε να μονοποιήσετε αποτελεσματικά το παιχνίδι σας. Θυμηθείτε ότι δεν χρειάζεται να έχετε οικονομικούς στόχους για να διασκεδάσετε δημιουργώντας ένα παιχνίδι Roblox.

### [Τουρίστες και ντόπιοι](#τουρίστες-και-ντόπιοι)[](#τουρίστες-και-ντόπιοι)

Μπορεί να είναι χρήσιμο να σκεφτείτε τους χρήστες του Roblox σε δύο κατηγορίες:

-

Οι τουρίστες  συνήθως πηδούν από το ένα παιχνίδι στο άλλο, δίνοντας προτεραιότητα στην ποικιλία αντί για το βάθος. Προτιμούν αντικείμενα με άμεσες επιδράσεις, είτε κάνοντάς τους το παιχνίδι πιο διασκεδαστικό είτε κάνοντάς τους να ξεχωρίζουν, προσκαλώντας άλλους χρήστες να αναρωτηθούν πώς και πού απέκτησαν το αντικείμενο.

-

Οι ντόπιοι  είναι πιο πιθανό να εστιάσουν σε ένα συγκεκριμένο παιχνίδι ή σε ένα μικρότερο σύνολο παιχνιδιών. Εμπλέκονται πιο βαθιά και συνήθως σχηματίζουν σχεδόν όλη τη βάση χρηστών που είναι ενεργοί σε ένα παιχνίδι. Ενδιαφέρονται περισσότερο για αντικείμενα με μακροπρόθεσμα οφέλη, όπως ένα [battle pass](/docs/en-us/production/game-design/season-pass-design) .

Για να μάθετε περισσότερα σχετικά με το πώς να σχεδιάσετε το παιχνίδι σας με γνώμονα τους χρήστες του Roblox, δείτε το [Σχεδιασμός για Roblox](/docs/en-us/production/game-design/design-for-roblox) .

### [Κοινωνικά χαρακτηριστικά](#κοινωνικά-χαρακτηριστικά)[](#κοινωνικά-χαρακτηριστικά)

Οι χρήστες του Roblox τείνουν να απολαμβάνουν παιχνίδια που δίνουν έμφαση στην κοινωνική αλληλεπίδραση. Για παράδειγμα, η ύπαρξη αντικειμένων ή εκδηλώσεων που είναι διαθέσιμα μόνο για περιορισμένο χρόνο  μπορεί να δημιουργήσει ενθουσιασμό γύρω από αυτό το περιεχόμενο. Ένα σύστημα ανταλλαγής  ενθαρρύνει τους χρήστες να αλληλεπιδρούν. Ενώ και τα δύο συστήματα μπορούν να είναι επιτυχημένα από μόνα τους, είναι ιδιαίτερα αποτελεσματικά όταν συνδυάζονται.

### [Ζωντανές λειτουργίες](#ζωντανές-λειτουργίες)[](#ζωντανές-λειτουργίες)

Η υποστήριξη μετά την κυκλοφορία είναι σε πολλές περιπτώσεις πιο εύκολη στο Roblox από ότι σε άλλες πλατφόρμες, καθώς μπορείτε γρήγορα να αποστείλετε ενημερώσεις για να βελτιώσετε το παιχνίδι σας.

Συχνές  ενημερώσεις περιεχομένου μπορεί να είναι χρήσιμες αν θέλετε να διατηρήσετε την εμπλοκή με το παιχνίδι σας με την πάροδο του χρόνου. Οι χρήστες του Roblox είναι συνηθισμένοι να εμπλέκονται με τακτικές ενημερώσεις, και μπορεί να είναι πολύ πιο δύσκολο να επαναφέρετε το ενδιαφέρον ενός χρήστη από ότι να διατηρήσετε τους ενεργούς. Μια εβδομαδιαία συχνότητα  για τις ενημερώσεις είναι ιδανική. Στο ελάχιστο, στοχεύστε σε μηνιαίες ενημερώσεις. Για μια συζήτηση σχετικά με τη συχνότητα περιεχομένου, δείτε το Level Up [εργαστήριο συχνότητας περιεχομένου](/docs/en-us/production/game-design/content-updates) .

Κατά το σχεδιασμό ενημερώσεων, κρατήστε τις επικεντρωμένες σε ένα συγκεκριμένο θέμα . Αυτό διευκολύνει τους χρήστες να κατανοήσουν τη νέα ενημέρωση και να καταλάβουν ποιο περιεχόμενο είναι νέο όταν συνδέονται. Βοηθά επίσης να συντονίσετε το περιεχόμενο και τα προωθητικά σας στοιχεία. Για παράδειγμα, αν προσθέτετε ένα νέο Ζωολογικό Κήπο στο παιχνίδι σας ρόλων, βεβαιωθείτε ότι όλο το νέο περιεχόμενο έχει κάποια σύνδεση με το θέμα του Ζωολογικού Κήπου.

Μην φοβάστε να κάνετε τους χρήστες να κερδίσουν την πρόσβαση  σε νέο περιεχόμενο. Οι νέοι χρήστες θα σπεύσουν να παίξουν τις νέες ενημερώσεις, αλλά αν δεν αισθάνονται ότι έχουν κατορθώσει  κάτι στο παιχνίδι, μπορεί να αποσυρθούν σύντομα μετά. Μπορείτε να δημιουργήσετε μια αίσθηση κέρδους μιας ενημέρωσης είτε μέσω της μονοποίησης του περιεχομένου της ενημέρωσης είτε δημιουργώντας προαπαιτούμενες συνθήκες για να παίξετε το νέο περιεχόμενο.

Για να μάθετε περισσότερα σχετικά με το πώς να σχεδιάσετε αποτελεσματική υποστήριξη μετά την κυκλοφορία για το παιχνίδι σας, δείτε τα [βασικά στοιχεία ζωντανών λειτουργιών](/docs/en-us/production/game-design/liveops-essentials) .

### [Διαχειριζόμενη τιμολόγηση](#διαχειριζόμενη-τιμολόγηση)[](#διαχειριζόμενη-τιμολόγηση)

Εγγράφεστε μία φορά, επιλέγετε ποια αντικείμενα να συμπεριλάβετε και η διαχειριζόμενη τιμολόγηση διατηρεί τις τιμές σας βελτιστοποιημένες σε προϊόντα και περιοχές με την πάροδο του χρόνου.

Η [βελτιστοποίηση τιμών](/docs/en-us/production/monetization/price-optimization)  σας επιτρέπει να βρείτε τα καλύτερα σημεία τιμής για τα πάσα και τα προϊόντα προγραμματιστών σας, κάτι που μπορεί να σας βοηθήσει να κερδίσετε περισσότερα χρήματα με την πάροδο του χρόνου, διατηρώντας τις τιμές σας ανταγωνιστικές.

Η [πληρωμένη πρόσβαση σε τοπικό νόμισμα](/docs/en-us/production/monetization/paid-access-local-currency)  σας επιτρέπει να χρεώνετε τους χρήστες μια μία φορά χρέωση σε τοπικό νόμισμα  για να αποκτήσουν πρόσβαση στο παιχνίδι σας. Ενώ οι ιδιωτικοί διακομιστές μπορεί να είναι δωρεάν, μπορείτε επίσης να χρησιμοποιήσετε τους ιδιωτικούς διακομιστές ως μέθοδο μονοποίησης χρεώνοντας τους χρήστες που θέλουν να αποκτήσουν πρόσβαση σε ιδιωτικούς διακομιστές μια μηνιαία Robux χρέωση .

### [Τέλη καταλόγου και προμήθειες](#τέλη-καταλόγου-και-προμήθειες)[](#τέλη-καταλόγου-και-προμήθειες)

Μπορείτε να δημιουργήσετε και να πουλήσετε αξεσουάρ και ρούχα στην Αγορά. Αφού πληρώσετε την χρέωση ανέβασμα και υποβάλετε ένα νέο περιουσιακό στοιχείο για έγκριση, η ομάδα μετριασμού εξετάζει το περιουσιακό σας στοιχείο και, εάν εγκριθεί, προσθέτει το περιουσιακό σας στοιχείο στον κατάλογο.

Θα λάβετε μια [προμήθεια](/docs/en-us/marketplace/marketplace-fees-and-commissions)  κάθε φορά που οι χρήστες αγοράζουν το αντικείμενο του καταλόγου σας. Εάν οι χρήστες αγοράσουν το αντικείμενο του καταλόγου σας εντός ενός παιχνιδιού χρησιμοποιώντας το [μενού επιθεώρησης avatar](/docs/en-us/players/avatar-inspect-menu)  ή την [υπηρεσία επεξεργασίας avatar](/docs/en-us/players/avatar-editor) , ο ιδιοκτήτης του παιχνιδιού λαμβάνει επίσης μια προμήθεια.

### [Πρόσθετα και Μοντέλα](#πρόσθετα-και-μοντέλα)[](#πρόσθετα-και-μοντέλα)

Ένα [πρόσθετο](/docs/en-us/studio/plugins)  είναι μια επέκταση που προσθέτει επιπλέον λειτουργικότητα στο Studio, και ένα [μοντέλο](/docs/en-us/parts/models)  είναι ένας επαναχρησιμοποιήσιμος τύπος περιουσιακού στοιχείου. Μπορείτε να προσφέρετε και τα δύο σε άλλους δημιουργούς στο [Creator Store](/docs/en-us/production/creator-store)  δωρεάν, ή μπορείτε να τα πουλήσετε για Δολάρια Ηνωμένων Πολιτειών  (η ελάχιστη τιμή είναι 4,99 γ ι α π ρ ο ˊ σ θ ε τ α κ α ι 2 , 99 για πρόσθετα και 2,99 γ ι α π ρ ο ˊ σ θε τα κ α ι 2 , 99  για μοντέλα). Το Roblox προσφέρει ένα ηγετικό μερίδιο εσόδων για αυτές τις πωλήσεις, καθώς μόνο οι φόροι και οι χρεώσεις επεξεργασίας πληρωμών αφαιρούνται. Για περισσότερες πληροφορίες σχετικά με την πώληση προσθέτων και μοντέλων, δείτε το [Creator Store - Διανομή και πώληση περιουσιακών στοιχείων](/docs/en-us/production/creator-store#distribute-and-sell-assets) .

Υπάρχει μια 30ήμερη κράτηση για κάθε αγορά. Το Roblox κρατά το μερίδιο σας από την πώληση για 30 ημέρες, ξεκινώντας από την ημερομηνία πώλησης.

## [Κατευθυντήριες γραμμές](#κατευθυντήριες-γραμμές)[](#κατευθυντήριες-γραμμές)

Καθώς σχεδιάζετε και εφαρμόζετε προϊόντα μονοποίησης στα παιχνίδια σας, εξετάστε τις παρακάτω κατευθυντήριες γραμμές για να διασφαλίσετε ότι οι μέθοδοι μονοποίησής σας είναι κατάλληλες για όλα τα κοινά στην πλατφόρμα.

### [Παρουσίαση προϊόντων](#παρουσίαση-προϊόντων)[](#παρουσίαση-προϊόντων)

Για να διατηρήσετε την ασφάλεια και τη δικαιοσύνη, πρέπει να παρουσιάσετε τα προϊόντα μονοποίησης με τρόπο που να είναι διαφανής, ειλικρινής και φιλικός προς τον χρήστη. Για παράδειγμα, εάν προσφέρετε εκπτώσεις, αυτές πρέπει να είναι γνήσιες  και δίκαιες :

-

Μια έκπτωση δεν είναι γνήσια εάν ένα αντικείμενο είναι πάντα "σε προσφορά" για το ίδιο ποσό Robux.

-

Μια έκπτωση δεν είναι δίκαιη εάν προσφέρεται μόνο για πολύ σύντομο χρονικό διάστημα, πιέζοντας τους χρήστες να κάνουν μια αγορά όσο το δυνατόν πιο γρήγορα.

Οι χρήστες δεν πρέπει ποτέ να παραπλανώνται, να μπερδεύονται ή να πιέζονται σε αγορές με τρόπους που δεν είχαν σκοπό, και θα πρέπει πάντα να έχουν την ελευθερία να κάνουν μια σαφή, σκόπιμη επιλογή για να αποκτήσουν μια συνδρομή ή να ξοδέψουν Robux σε ένα συγκεκριμένο αντικείμενο. Ως γενική καθοδήγηση, υπάρχουν ορισμένες πρακτικές που πρέπει να αποφεύγονται ανά πάσα στιγμή κατά την παρουσίαση προϊόντων μονοποίησης στο κοινό σας:

-

Μην ισχυρίζεστε ότι μια συνδρομή ή ένα αντικείμενο είναι σχεδόν εξαντλημένο ή διαθέσιμο μόνο για σύντομο χρονικό διάστημα αν δεν είναι αλήθεια.

-

Μην χρησιμοποιείτε ένα χρονομετρητή αντίστροφης μέτρησης που δεν είναι ακριβής ή επανεκκινείται αυτόματα για το ίδιο αντικείμενο.

Για παράδειγμα, εάν το παιχνίδι σας περιλαμβάνει μια "προσφορά της ημέρας" που λέει ότι είναι διαθέσιμη μόνο για 24 ώρες, αλλά στη συνέχεια δείχνετε το ίδιο μήνυμα στους χρήστες κάθε φορά που συνδέονται και δεν σταματά ποτέ να είναι διαθέσιμο, έχετε δημιουργήσει μια ψευδή αίσθηση επείγοντος που δεν είναι φιλική προς τον χρήστη.

### [Προώθηση σε παγκόσμιες κοινότητες](#προώθηση-σε-παγκόσμιες-κοινότητες)[](#προώθηση-σε-παγκόσμιες-κοινότητες)

Το Roblox είναι μια παγκόσμια κοινότητα για χρήστες όλων των ηλικιών, επομένως οι προωθήσεις εντός των παιχνιδιών σας θα πρέπει να είναι κατάλληλες για όλα τα κοινά από προεπιλογή. Εάν ορισμένα προϊόντα μονοποίησης περιορίζονται σε ορισμένες τοποθεσίες, όπως τα πληρωμένα τυχαία αντικείμενα, το Roblox παρέχει το API [PolicyService](/docs/en-us/reference/engine/classes/PolicyService)  για να σας βοηθήσει να διασφαλίσετε ότι αυτά τα προϊόντα είναι ορατά μόνο σε επιλέξιμους χρήστες.

Το [PolicyService](/docs/en-us/reference/engine/classes/PolicyService)  επιστρέφει εάν ένας χρήστης είναι επιλέξιμος για συγκεκριμένα αντικείμενα ή χαρακτηριστικά σύμφωνα με την τοποθεσία, την ηλικία και την πλατφόρμα τους. Πρέπει να ενσωματώσετε αυτό το API στο παιχνίδι σας για να πληροίτε τις υποχρεώσεις συμμόρφωσης, συμπεριλαμβανομένου του προσδιορισμού εάν κάθε χρήστης είναι:

-

Επιλέξιμος να αγοράσει συνδρομές ή προϊόντα εμπορίου.

-

Επιτρέπεται να έχει πληρωμένα τυχαία αντικείμενα, πληρωμένες ανταλλαγές αντικειμένων ή να βλέπει εμβληματικές διαφημίσεις.

Εάν ένας χρήστης μπορεί να χρησιμοποιήσει Robux ή κάτι άλλο που αποκτήθηκε με Robux για να αποκτήσει μια τυχαία ανταμοιβή, είστε υποχρεωμένοι να χρησιμοποιήσετε το [PolicyService](/docs/en-us/reference/engine/classes/PolicyService)  για να αποκλείσετε αυτή τη δυνατότητα για χρήστες που δεν επιτρέπεται να χρησιμοποιούν τυχαία αντικείμενα αντάξια Robux.

Ως γενική καθοδήγηση, αποφύγετε τη χρήση πιεστικών ή επείγοντων μηνυμάτων όταν αλληλεπιδράτε με ανηλίκους, καθώς η γλώσσα υψηλής πίεσης μπορεί να είναι συντριπτική:

| ** Γλώσσα προς αποφυγή** | | ** Συνιστώμενες εναλλακτικές** |
| --- | --- |
| "ΑΠΟΚΤΗΣΤΕ ΤΟ ΤΩΡΑ" | | "Δείτε το αντικείμενο" |
| "ΤΕΛΕΥΤΑΙΑ ΕΥΚΑΙΡΙΑ, ΔΡΑΣΤΕ ΤΩΡΑ" | | "Δείτε την τιμή" |
| "ΑΓΟΡΑΣΤΕ ΠΡΙΝ ΧΑΘΕΙ!" | | "Ανοίξτε το κατάστημα" |
