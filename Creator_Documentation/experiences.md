# Get started with experiences on Roblox

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/experiences.md)

Roblox is a 3D creation platform that provides an all-in-one IDE that includes the Roblox Engine, a client emulator, and all the tools and APIs you need to start creating Roblox experiences.

## Play and create with templates

Roblox Studio has a variety of templates that you can edit and play without prior knowledge. Give them a try and add on to them when you're ready!

![](https://prod.docsiteassets.roblox.com/assets/landing/get-started/Platformer-Template.png)

Platformer Build your own 3D platformer  with customizable platforms, coin pickups, and double-jump, dashing, rolling, and long jump character mechanics!

[Play](roblox://placeId=18636963376)

![](https://prod.docsiteassets.roblox.com/assets/landing/get-started/Laser-Tag-Template.jpg)

Laser tag Build your own first-person shooter  with customizable blasters, round systems, and modular building assets to reconfigure a high-quality arena!

[Play](roblox://placeId=17823019220)

![](https://prod.docsiteassets.roblox.com/assets/landing/get-started/Racing-Detailed.jpg)

Racing Build your own kart racer  with a customizable driving mechanics, checkpoints, and modular winding track pieces that you can restructure for countless courses!

[Play](roblox://placeId=16078915506)

## Learn with curriculum paths

To dive deeper, follow along with guided curriculum that teaches you the skills you need to create and monetize your experiences.

Environmental art Environmental Art teaches you how to create a high-quality environment for a laser tag experience.

[Create](/docs/en-us/./tutorials/curriculums/environmental-art)

Gameplay scripting Gameplay Scripting teaches you how to organize and implement the scripting logic for large, complex projects.

[Create](/docs/en-us/./tutorials/curriculums/gameplay-scripting)

UI Design UI Design teaches you how to plan and implement UI components for unique user flows.

[Create](/docs/en-us/./tutorials/curriculums/user-interface-design)
