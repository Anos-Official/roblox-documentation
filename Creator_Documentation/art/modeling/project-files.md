# Modeling project files and references

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/art/modeling/project-files.md)

The following .fbx , .blend , and .ma  project files are available to use as templates or as reference:

Maple leaf tree

![A green maple tree mesh](https://prod.docsiteassets.roblox.com/assets/art/resources/Tree-Resource.png)

A skinned tree model with the soil, branches, and leaves as separate meshes bound to a single armature. This is packaged with UV textures that can be applied with [SurfaceAppearance](/docs/en-us/reference/engine/classes/SurfaceAppearance) . This is an advanced version of the tree model used in the [Skin a simple mesh](/docs/en-us/art/modeling/skin-a-simple-mesh)  guide.

[Download](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/MapleLeafTree_S3.zip)

Shoebot

![A white round robot with arms and orange trim.](https://prod.docsiteassets.roblox.com/assets/art/resources/Shoebot-Resource.png)

A robot non-player character used in the [Beyond The Dark](https://www.roblox.com/games/7208091524/Beyond-the-Dark-Vistech-Showcase)  showcase.

[Download](https://prod.docsiteassets.roblox.com/assets/modeling/meshes/reference-files/shoebot-base-model.fbx)

Creature

![A black and blue alien creature with tentacles.](https://prod.docsiteassets.roblox.com/assets/art/resources/Creature-Resource.png)

Creature model from the [Beyond The Dark](https://www.roblox.com/games/7208091524/Beyond-the-Dark-Vistech-Showcase)  showcase. This model is made up of 11 meshes and over 50 bones.

[Download](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/CreatureModel.fbx)

## [Avatar and accessories](#avatar-and-accessories)[](#avatar-and-accessories)

The following include examples and templates utilizing Roblox's required [avatar components](/docs/en-us/avatar/character-bodies#character-body-components) . Many of these project files and references require additional configuration in your modeling software before importing into Studio as a complete avatar character. See [Character bodies](/docs/en-us/avatar/character-bodies)  for additional resources and template usage instruction.

### [References](#references)[](#references)

Fish person

![A blue-green scaly creature with a bulb-ish head ornament.](https://prod.docsiteassets.roblox.com/assets/art/resources/Fish-Person-Resource.png)

A rigged and skinned humanoid character model with a full body cage, facial animation rig, and associated PBR texture maps.
 If this asset were to be uploaded to the Marketplace, the bulb antenna must be a separate head accessory and not part of the character's head geometry.

[Download](https://prod.docsiteassets.roblox.com/assets/avatar/dynamic-heads/reference-files/Fish-Person.zip)

Goblin

![A brown goblin with bright green eyes.](https://prod.docsiteassets.roblox.com/assets/art/resources/Goblin-Resource.png)

A rigged and skinned humanoid character model with a full body cage, facial animation rig.

[Download](https://prod.docsiteassets.roblox.com/assets/avatar/dynamic-heads/reference-files/GoblinCharacter.zip)

Blocky

![A colorless blocky-like character.](https://prod.docsiteassets.roblox.com/assets/art/resources/Blocky-Resource.png)

A Blocky character model with an animatable head and a full body cage.

[Download](https://prod.docsiteassets.roblox.com/assets/avatar/dynamic-heads/reference-files/BlockyCharacter.fbx)

Lola

![A pink-haired character complete with brown jacket, goggles, leggings, and pants.](https://prod.docsiteassets.roblox.com/assets/art/resources/Lola-Resource.png)

A skinned R15 avatar character created from the [Skin a humanoid model](/docs/en-us/art/modeling/skin-a-humanoid-model)  guide. Since this reference model doesn't yet have [inner and outer cage mesh data](/docs/en-us/avatar/character-bodies/specifications#outer-cages) , this model can't equip layered accessories.

[Download](https://prod.docsiteassets.roblox.com/assets/modeling/skinned-meshes/Lola.fbx)

Tshirt - uncaged

![A tie-dye tshirt with a rainbow of colors in a general spiral toward the torso.](https://prod.docsiteassets.roblox.com/assets/art/resources/Tshirt-Resource.png)

Uncaged example clothing ready for caging in a 3D modeling software.

[Download](https://prod.docsiteassets.roblox.com/assets/accessories/reference-files/Tshirt-model.fbx)

Clothing examples

![](https://prod.docsiteassets.roblox.com/assets/art/Generic-Icon.png)

Caged 3D accessory models and associated PBR textures. Ready for import into Studio or in a modeling tool.

[Download](https://prod.docsiteassets.roblox.com/assets/accessories/reference-files/Additional-FBX-assets.zip)

Caging Examples

![](https://prod.docsiteassets.roblox.com/assets/art/Additional-Caging-Examples.png)

Additional caged clothing items from How to cage Roblox's 3D [clothing video guide](https://www.youtube.com/watch?v=QwZaA9Gc-WQ) .

[Download](https://prod.docsiteassets.roblox.com/assets/accessories/reference-files/Caging-examples.zip)

Classic mannequin

![A white untextured mannequin in the blocky style.](https://prod.docsiteassets.roblox.com/assets/art/resources/Body-Scale-Classic.png)

A blank mannequin using Roblox's [Classic](/docs/en-us/avatar/character-bodies/specifications#classic)  avatar proportions.

### [Project files](#project-files)[](#project-files)

R15 rig and attachments

![A Blender visualization of bones and attachment meshes in a neutral humanoid pose.](https://prod.docsiteassets.roblox.com/assets/art/resources/Rig-And-Attachments-Resource.png)

[Standard R15 rig](/docs/en-us/avatar/character-bodies/specifications#standard-r15-rigs)  template for Blender. Use this template for rigging bodies  and clothing  items.

[Download (.blend, .ma, .fbx)](https://prod.docsiteassets.roblox.com/assets/modeling/meshes/reference-files/Rig_and_Attachments_Templates.zip)

Cages for clothing

![A humanoid shaped mesh in a neutral A-pose.](https://prod.docsiteassets.roblox.com/assets/art/resources/Clothing-Cage-Resource.png)

Project files for creation, includes a full-body inner and outer cage mesh for creation of clothing  items.

[Download (.blend, .ma, .fbx)](https://prod.docsiteassets.roblox.com/assets/modeling/meshes/reference-files/Clothing_Cage_Templates.zip)

Cages for bodies

![A humanoid shaped mesh in a neutral A-pose. Each section of the mesh is colored differently based on the body part.](https://prod.docsiteassets.roblox.com/assets/art/resources/Body-Cages-Resource.png)

Project files for creation, includes the 15 individual body part cages required for caging your avatar bodies .

[Download (.blend, .ma, .fbx)](https://prod.docsiteassets.roblox.com/assets/modeling/meshes/reference-files/Body_Cage_Templates.zip)

Combined project files

![](https://prod.docsiteassets.roblox.com/assets/art/Generic-Icon.png)

Template file containing all content from previous templates, includes rig skeleton, body cages, attachment points.

 Use this template to rig and cage bodies and clothing.

[Download (.blend, .ma, .fbx)](https://prod.docsiteassets.roblox.com/assets/modeling/meshes/reference-files/Combined_Templates.zip)
