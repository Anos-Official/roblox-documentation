# Booleans

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/luau/booleans.md)

The boolean  data type, or bool , has a value of either true  or false .

## [Conditionals](#conditionals)[](#conditionals)

If a value isn't false  or nil , Luau evaluates it as true  in [conditional statements](/docs/en-us/luau/control-structures#if-statements) . Unlike many other languages, Luau considers both zero and the empty string as true .

## [Operators](#operators)[](#operators)

You can formulate complex conditions with [relational](/docs/en-us/luau/operators#relational)  and [logical](/docs/en-us/luau/operators#logical)  operators.
