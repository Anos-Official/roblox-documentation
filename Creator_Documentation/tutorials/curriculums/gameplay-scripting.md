# Gameplay scripting curriculum

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/tutorials/curriculums/gameplay-scripting/index.md)

Gameplay scripting  is the discipline of programming the behavior that makes games engaging and fun to play, such as their logic, movement, events, and interactions between objects in the 3D space.

You'll learn the gameplay scripting for a first-person shooter laser tag game by following the general organization and key implementation details of a large, complex project, including several opportunities to create new behavior with custom values.

This course is intended for readers who are familiar with general coding concepts, Studio's data model, and the client-server relationship. If you need help learning how to code, try [coding fundamentals](/docs/en-us/tutorials/fundamentals/coding-1/coding-fundamentals) .

## [Course Contents](#course-contents)[](#course-contents)

Chapter 1 - Create teams

Learn how to [sort players into teams](/docs/en-us/tutorials/curriculums/gameplay-scripting/create-teams)  when a round is active.

Chapter 2 - Spawn and respawn

Learn how to [trigger unique actions](/docs/en-us/tutorials/curriculums/gameplay-scripting/spawn-respawn)  when players spawn and respawn back into a round.

Chapter 3 - Add rounds

Learn how to [implement rounds](/docs/en-us/tutorials/curriculums/gameplay-scripting/add-rounds)  that track points, display final results, and reset teams.

Chapter 4 - Implement blasters

Learn how to [script blast behavior](/docs/en-us/tutorials/curriculums/gameplay-scripting/implement-blasters)  for two different blaster types.

Chapter 5 - Detect hits

Learn how to [perform hit detection](/docs/en-us/tutorials/curriculums/gameplay-scripting/detect-hits)  from blast data, and allocate damage to reduce player health.
