# Background specifications

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/avatar/backgrounds/specifications.md)

Backgrounds for avatars require specific configuration standards to ensure all backgrounds work as expected across the platform. Before you start the export process from your 2D editing software, verify that your image meets the following file and content specifications and guidelines to display correctly in the 3D avatar viewer and on profile pages.

## [File requirements](#file-requirements)[](#file-requirements)

| Requirement | | Specifications |
| --- | --- |
| Resolution | | Exactly 2560 x 1440 pixels |
| Color | | sRGB |
| Alpha channel | | None, export flattened RGB with no transparency.

Many art tools export a .png  with an alpha channel, even when the image contains no transparent pixels. It's important to turn off the alpha channel in the export settings, or flatten the image and export a .jpg  instead.

 |
| File format | | .jpg , .png , .tga , or .bmp |
| File size | | 20 MB or smaller |

Roblox applies an edge fade so the background blends into surrounding UI, so it's important to export the image without a fade of your own. For information on where you should place detail inside the frame, see [Template zones](/docs/en-us/avatar/backgrounds#template-zones) .

## [Content requirements](#content-requirements)[](#content-requirements)

Like all avatar assets, backgrounds must follow Roblox's [Community Standards](https://en.help.roblox.com/hc/en-us/articles/203313410-Roblox-Community-Standards)  and [Marketplace policies](/docs/en-us/marketplace/marketplace-policy) .
