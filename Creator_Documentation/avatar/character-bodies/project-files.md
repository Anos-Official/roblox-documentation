# Character body reference files

English

[Edit](https://github.com/Roblox/creator-docs/blob/main/content/en-us/avatar/character-bodies/project-files.md)

The following project files and templates are specifically helpful when creating a character body for an avatar. For a comprehensive list of Roblox's official downloadable content for avatars, such as rigid and layered accessory templates, see [Resources](/docs/en-us/avatar/resources) .

## [Project files](#project-files)[](#project-files)

The following .fbx , .blend , and .ma  project files are available to use as examples, boilerplate, or as a reference for your own custom character bodies for avatars:

## [Templates](#templates)[](#templates)

If you are creating custom character body models, you can choose from a variety of starting templates that best match your final design to save time on creating the [avatar components](/docs/en-us/avatar/character-bodies#character-body-components) . For important information on using these template files, see [Create with templates](/docs/en-us/art/characters/creating#template-files) .

Each .zip  contains a .blend , .fbx , and PBR texture .png  files for that template model. If using Blender or following the [template creation guides](/docs/en-us/art/characters/creating) , use the .blend  project.

If you are using Roblox's avatar template files, you must perform the [cleanup steps](/docs/en-us/art/characters/creating/combine-head-geometry)  in order for the assets to properly validate before publishing to the Marketplace.
