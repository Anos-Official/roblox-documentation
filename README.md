# Roblox Creator Documentation Archive

This folder is generated by **Roblox Docs Archiver 1.0.0**.

- Open [INDEX.md](INDEX.md) to browse downloaded documents.
- Open [DOWNLOAD_REPORT.md](DOWNLOAD_REPORT.md) for errors, source-index status, and duplicate information.
- `manifest.json` contains source URLs, local paths, HTTP status, hashes, timestamps, validators, and errors.
- Original URLs are also embedded at the top of each archived Markdown document.

## Updating the archive

Run the archiver again from the source package. It uses conditional HTTP requests where available and only rewrites changed documents. Use `--retry-failed` to reattempt pages with recorded failures.

## Important

A page is only considered archived when its content was successfully retrieved and written. A page with a failed request remains visible in the manifest and download report. The archive is limited to documentation pages discoverable through Roblox's official indexes and same-site documentation links; it does not crawl unrelated domains.
